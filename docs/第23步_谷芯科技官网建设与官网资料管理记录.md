# 第 23 步：谷芯科技官网建设与官网资料管理记录

## 本次目标

建设“山西谷芯科技有限公司 / 谷芯科技”对外官网，并把官网资料管理能力集成到现有谷芯快检云管理后台。官网用于展示食品安全快检室整体配套、检测设备、试剂耗材、合格证打印、数据平台和谷芯快检云能力。

## 已完成内容

1. 新增官网前端应用 `website/`，技术栈为 Vue 3 + Vite + TypeScript。
2. 新增后台菜单“官网”，包含“官网资料”和“官网配置”。
3. 新增官网资料上传、编辑、公开/隐藏、推荐、排序、删除能力。
4. 新增官网公开接口，官网只读取公开资料和公开配置。
5. 新增官网配置接口，支持首页标题、副标题、按钮文案、联系电话、微信说明、公司简介和展示开关。
6. Docker Compose 新增 `website` 服务。
7. Nginx 预留 `www.gxkjy.com` 和 `gxkjy.com` 的 HTTP 官网入口。
8. 部署到 ECS 正式测试环境，未影响现有 `api/admin/cert` 三个域名。

## 上传安全限制

1. 单文件最大 20MB。
2. 允许 jpg、jpeg、png、webp、pdf、doc、docx、xls、xlsx、ppt、pptx。
3. 禁止 exe、js、html、sh、bat、php 等可执行或高风险文件。
4. 后端同时校验扩展名和 MIME。
5. 文件随机命名，避免覆盖。
6. 删除使用软删除，公开接口不返回已删除资料。
7. Public 接口不返回本地真实路径、上传人、内部备注、密码、密钥、token。
