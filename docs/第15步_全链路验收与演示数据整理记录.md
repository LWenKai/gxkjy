# 第15步 全链路验收与演示数据整理记录

## 当前系统已具备的功能

- 后台管理：管理员登录、数据看板、企业管理、企业账号管理、企业公开资料、厂家接口、设备管理、测试检测数据录入、检测记录查看与软处理、合格证查看、产品库、操作日志、系统设置。
- 客户移动端：客户账号登录、首页统计、检测记录列表与详情、可开证记录、开具合格证、已开证记录、合格证详情、复制扫码链接、标签预览、模拟打印、作废合格证、我的页面。
- 扫码公开页：通过公开链接查看合格证、检测结果、企业公开资料，支持正常、作废、无效链接三种状态。
- 后端基础能力：统一返回格式、后台 JWT、客户 JWT、企业数据隔离、服务到期拦截、合格证编号、公开随机 token、模拟打印日志、操作日志。
- 部署能力：ECS 单机 Docker Compose、MySQL、backend、admin-web、public-h5、Nginx、MySQL 备份脚本、临时 IP HTTP 访问。

## 当前系统暂不具备的功能

- 未配置 `gxkjy.com` 正式域名、HTTPS 证书、小程序合法请求域名。
- 未发布微信小程序正式版或体验版。
- 未接入真实检测仪器厂家上传接口联调。
- 未接入真实蓝牙打印机和优博讯 K329 SDK。
- 未接入真实 OSS 文件上传，本阶段仍通过图片 URL 验证公开展示。
- 未做复杂权限、收费系统、Excel 导出、客户自定义模板和复杂统计大屏。
- 当前测试环境不能用于正式客户生产数据。
