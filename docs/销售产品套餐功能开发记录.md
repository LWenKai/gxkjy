# 销售产品套餐功能开发记录

## 目标

在后台「销售管理 - 销售产品库」内增加销售套餐能力，用于维护基础版、升级版、高级版、定制套餐等组合销售方案。报价时可选择套餐，系统自动展开套餐内产品明细，并使用套餐内预设价格。

## 实现内容

1. 新增销售套餐数据结构：
   - `sales_product_packages`
   - `sales_product_package_items`
2. 报价明细增加套餐来源：
   - `source_package_id`
   - `source_package_name_snapshot`
3. 后台新增接口：
   - `GET /api/admin/sales-product-packages`
   - `POST /api/admin/sales-product-packages`
   - `GET /api/admin/sales-product-packages/:id`
   - `PUT /api/admin/sales-product-packages/:id`
   - `DELETE /api/admin/sales-product-packages/:id`
   - `PATCH /api/admin/sales-product-packages/:id/active`
4. 销售产品库页面增加页签：
   - 单品库
   - 销售套餐
5. 客户详情报价单增加：
   - 添加产品
   - 添加套餐

## 业务规则

1. 套餐采用明细价汇总模式。
2. 每个套餐产品单独维护数量、套餐内单价、小计和备注。
3. 报价选择套餐后自动展开所有产品明细。
4. 报价单、成交订单和复购提醒仍按产品明细流转。
5. 第一版不预置默认套餐，由后台按真实产品和价格维护。
