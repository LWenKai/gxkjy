# 检测仪数据对接内部联调操作手册

本文供谷芯内部使用，用于和检测仪厂家联调。文档中可以提到 `access_secret` 的概念，但不得写入真实密钥。

## 一、联调前准备

1. 确认厂家名称、联系人和技术负责人；
2. 获取检测仪型号和设备编号；
3. 获取厂家当前数据字段样例；
4. 确认厂家是否支持 HTTPS、JSON、HMAC-SHA256；
5. 确认厂家是否能配置上传地址、厂家编码、设备编号和密钥；
6. 确认是否有测试设备或远程联调环境。

## 二、后台配置厂家接口

在管理后台进入“厂家接口”：

1. 新增厂家接口；
2. 填写厂家名称；
3. 设置 `manufacturer_code`，例如 `GXTEST`；
4. 设置 `access_secret`，使用随机强密钥；
5. 接口类型选择 HTTP API；
6. 状态设置为启用；
7. 保存后不要把密钥展示给无关人员。

注意：给厂家发送密钥时，只通过单独安全渠道发送，不写入公开文档。

## 三、绑定设备到企业

在后台进入“设备管理”或企业详情页：

1. 新增设备；
2. 选择对应厂家接口；
3. 填写设备名称；
4. 填写设备编号 `device_sn`；
5. 绑定到目标企业；
6. 确认设备状态为启用。

判断数据归属时，系统使用 `manufacturer_code + device_sn`，不是企业名称。

## 四、提供给厂家的测试参数

可以提供：

1. 上传地址；
2. `manufacturer_code`；
3. `device_sn`；
4. `access_secret`；
5. JSON 示例；
6. 签名规则；
7. 测试时间窗口；
8. 联系人电话。

不得提供：

1. 数据库密码；
2. JWT_SECRET；
3. OSS_SECRET；
4. 服务器密码；
5. 其他客户数据。

## 五、联调验证

### 合格数据

1. 厂家上传一条合格记录；
2. 后台检测记录能看到；
3. 客户端检测记录能看到；
4. 记录进入可开证列表；
5. 检测项目明细完整。

### 不合格数据

1. 厂家上传一条不合格记录；
2. 后台检测记录能看到；
3. 客户端检测记录能看到；
4. 不进入可开证列表；
5. 页面提示不能开证原因。

### 重复数据

1. 厂家重复上传同一个 `manufacturer_record_id`；
2. 系统不重复入库；
3. 返回重复已接收或类似提示；
4. 上传日志可查。

## 六、问题排查

### 签名错误

检查：

1. 待签名字段顺序是否一致；
2. timestamp 是否为秒级；
3. nonce 是否一致；
4. `sign` 是否小写 hex；
5. 是否误把 `items` 放入签名；
6. 厂家使用的密钥是否正确。

### 设备未绑定

检查：

1. `manufacturer_code` 是否存在；
2. `device_sn` 是否和后台一致；
3. 设备是否绑定企业；
4. 设备状态是否启用；
5. 厂家是否上传了错误设备编号。

### 重复上传

检查：

1. `manufacturer_record_id` 是否重复；
2. 厂家是否重试了同一条记录；
3. 系统是否已生成检测记录。

### 数据入库但不可开证

检查：

1. 整条记录结论是否为合格；
2. 记录状态是否正常；
3. 是否被标记异常、隐藏或作废；
4. 检测项目是否有不合格项。

## 七、上传日志能力

当前数据库已具备 `manufacturer_upload_logs` 表，可记录：

1. 厂家编码；
2. 设备编号；
3. 厂家检测记录 ID；
4. 上传请求摘要；
5. 处理结果；
6. 错误原因；
7. 上传时间。

后台上传日志页面如未完成，后续需要增加“厂家上传日志”页面，支持按厂家、设备、状态、时间筛选。

## 八、联调验收标准

1. 合格数据能入库并可开证；
2. 不合格数据能入库但不可开证；
3. 重复上传不会重复生成记录；
4. 签名错误会被拒绝；
5. 未绑定设备会被拒绝；
6. 上传日志可排查；
7. 不向 public 或 client 暴露厂家密钥；
8. 扫码公开页不展示设备编号和厂家编码。
