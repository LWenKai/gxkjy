# 后台管理端视觉升级说明

## 升级目标

让后台从“能用”提升到更像正式 SaaS 管理系统，适合演示、客户开通、设备绑定、检测记录和合格证日常维护。

## 本次优化

- 侧边栏改为深绿科技风。
- 顶部栏更清楚，保留系统名称和正式测试环境标识。
- Dashboard 增加欢迎区，统计卡片更精致。
- 表格、搜索区、卡片、按钮、状态标签统一。
- 小程序预览页手机外框和预览内容更接近真实小程序。

## 使用原则

- 后台页面以信息扫描和重复操作为主，不做花哨大屏。
- 表格字段保持清楚，长文本不撑开页面。
- 操作按钮分清主次，危险操作弱化。
- 详情页优先分区卡片展示。

## 当前边界

本次不新增复杂权限、不新增业务接口、不做真实检测仪器联调、不接真实打印机。
