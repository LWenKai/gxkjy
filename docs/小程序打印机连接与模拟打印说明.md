# 小程序打印机连接与模拟打印说明

## 当前状态

当前小程序仅支持模拟打印。系统不调用蓝牙，不连接真实打印机，不接优博讯 K329 SDK，也不申请微信蓝牙权限。

## 页面入口

打印机连接入口包括：

1. 首页打印机状态卡片
2. 合格证详情页
3. 打印预览页
4. 我的页面

## 模拟打印

打印预览页显示 60×80mm 标签结构化数据。点击“模拟打印”后，系统写入模拟打印日志，用于演示和流程验证。

## 后续真实打印需要准备

1. 目标打印机型号和 SDK。
2. 蓝牙连接协议或 BLE 指令文档。
3. 标签纸规格确认。
4. 打印失败重试规则。
5. 微信小程序蓝牙权限和真机调试。

真实打印接入前，不应把模拟打印宣传为真实打印。
