## 三、本次修复内容

1. 后台统一样式升级：页面卡片、搜索区、表格、按钮、详情区、自适应规则统一。
2. 登录页文案和视觉优化，更贴近正式 SaaS 管理系统。
3. 后台顶部增加“正式测试环境”标识。
4. 企业公开资料页面改造为“资料表单 + 本地上传 + 文件列表”结构。
5. 新增企业公开资料本地上传接口，支持图片和 PDF。
6. 新增文件信息编辑、公开/隐藏、删除接口。
7. 上传文件使用随机文件名，避免重名覆盖。
8. 上传文件通过 `https://api.gxkjy.com/uploads/...` 访问。
9. Docker Compose 增加上传目录持久化挂载。
10. Nginx 增加 `/uploads/` 静态访问配置。
11. 扫码公开页支持公开图片和 PDF 资料展示。
12. 扫码公开页增加查询时间和可信说明。

## 六、服务器文件存储

本次涉及服务器本地文件存储：

1. 宿主机目录：`/opt/gxkjy/uploads`
2. 后端容器写入目录：`/app/uploads`
3. Nginx 只读访问目录：`/var/www/uploads`
4. 访问 URL：`https://api.gxkjy.com/uploads/company-profiles/{companyId}/{randomFileName}`

上传限制：

1. 图片：jpg、jpeg、png、webp
2. 文件：pdf
3. 单文件大小：10MB
4. 文件名随机生成，原始文件名只作为展示名称保存
5. 不允许路径穿越
6. 不允许可执行文件

## 八、发现并修复的问题

1. 初次写入服务器 `.env` 的上传变量时，换行被错误拼接，导致后端没有读到 `UPLOAD_DIR`。已清理错误行，重新写入：
   - `UPLOAD_DIR=/opt/gxkjy/uploads`
   - `UPLOAD_PUBLIC_BASE_URL=https://api.gxkjy.com/uploads`
   - `UPLOAD_MAX_FILE_SIZE_MB=10`
2. 初次上传的测试文件写入了容器内部默认目录。已将文件迁移到 `/opt/gxkjy/uploads` 持久化目录，并重启后端使正确配置生效。
3. 重新验证上传后，新增文件 URL 前缀正确，删除接口可用。
