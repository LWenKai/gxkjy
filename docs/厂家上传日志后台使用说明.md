# 厂家上传日志后台使用说明

厂家上传日志用于检测仪真实对接时排查数据上传问题。

## 页面入口

后台菜单：

设备与数据 -> 厂家上传日志

## 可筛选条件

1. 厂家编码；
2. 设备编号；
3. 处理状态；
4. 上传时间。

## 页面字段

1. 上传时间；
2. 厂家编码；
3. 设备编号；
4. 厂家记录 ID；
5. 处理状态；
6. 归属企业；
7. 错误原因；
8. 请求摘要。

## 常见状态

1. 成功：数据已接收；
2. 重复上传：同一厂家记录已接收过；
3. 签名错误：厂家签名不正确；
4. 设备未绑定：设备编号未绑定到企业；
5. 格式错误：字段缺失或格式不符合要求；
6. 处理失败：服务端处理失败，需要进一步排查。

## 安全说明

日志页面不会展示厂家 access_secret、JWT、数据库密码、服务器路径或内部异常堆栈。

## 联调建议

检测仪厂家开始上传测试数据后，先按厂家编码和设备编号筛选日志；如果没有日志，先确认上传地址和网络；如果有失败日志，再根据错误原因逐项排查。
