# 第14步 客户移动端与扫码公开页优化记录

## 当前客户移动端已有功能

- 客户账号密码登录，登录后保存客户账号、企业信息和到期提醒。
- 首页可进入检测记录、开具合格证、已开证记录和我的页面。
- 检测记录列表、详情、可开证列表。
- 从合格检测记录开具合格证。
- 已开证记录列表、合格证详情、合格证作废。
- 标签预览和模拟打印日志写入。
- 客户端接口使用客户 JWT，并由后端按企业做数据隔离。

## 当前扫码公开页已有功能

- 支持 `/c/:publicToken` 路由。
- 可通过 `public_token` 查询合格证、检测结果、检测项目明细和企业公开资料。
- 支持正常、已作废、无效链接三种状态。
- 公开接口不需要登录，且不返回设备编号、厂家编码、客户账号、密钥等内部字段。

## 当前缺失或体验不好的地方

- 客户首页统计由页面临时拉列表计算，不够稳定，也缺少今日开证数和最近数据。
- 检测记录列表缺少样品/产品搜索。
- 已开证记录缺少产品/证书编号搜索。
- 合格证详情缺少明确的复制扫码链接入口。
- 打印预览主按钮文案不够贴近客户现场操作。
- 扫码公开页没有读取第 13 步新增的系统设置，底部说明和技术支持文案不能由后台配置。
- public-h5 企业公开资料展示未使用系统级展示开关。

## 本次实际优化内容

- 新增客户首页统计接口：`GET /api/client/dashboard/summary`。
- 新增公开系统设置接口：`GET /api/public/settings`。
- 客户端合格证列表、详情、开证、作废接口不再返回 `public_token`。
- 检测记录列表支持样品/产品搜索。
- 已开证记录支持产品名称或合格证编号搜索。
- 小程序首页改为真实统计：今日检测、可开证、今日开证、最近检测记录、最近合格证。
- 小程序检测详情补充限量值和不可开证原因。
- 小程序合格证详情补充复制扫码链接，作废后不显示标签预览入口。
- 小程序打印预览主操作调整为“模拟打印”，成功提示“模拟打印记录已保存”。
- 小程序我的页面补充联系电话、服务状态和“企业信息由后台维护”提示。
- public-h5 接入公开系统设置，失败时使用安全默认文案。
- public-h5 顶部、状态卡、底部说明和企业公开资料展示样式做了简化优化。

## 本次暂不处理内容及原因

- 不配置 `gxkjy.com`、HTTPS、小程序合法域名：域名实名认证仍在审核。
- 不发布微信小程序：当前仍是临时 IP + HTTP 测试环境。
- 不接真实检测仪器：厂家资料和联调尚未确认。
- 不接真实打印机、优博讯 K329 SDK：打印协议资料未确认。
- 不做 OSS 文件上传：本阶段仍使用图片 URL 方式验证公开展示。
- 不做收费、复杂权限、客户自定义模板、复杂统计大屏：超出第一版 MVP。
- 不修改后台默认管理员密码：本阶段要求保持现状，后续正式部署前再改。

## 是否涉及后端接口

涉及。

- 新增 `GET /api/client/dashboard/summary`，需要客户 JWT，只返回当前企业数据。
- 新增 `GET /api/public/settings`，无需登录，只返回公开展示类配置。
- 扩展 `GET /api/client/detection-records` 查询参数：`sample_name`。
- 扩展 `GET /api/client/certificates` 查询参数：`product_name`。
- 客户侧合格证返回移除内部 `public_token` 字段。

## 是否涉及数据库 migration

不涉及。本次只复用现有表和字段，不新增表，不新增字段，不重置数据库。
