# 管理后台交付与售后能力完善说明

本次后台重点补充谷芯内部交付和售后排查能力。

## 企业交付检查

企业详情页新增交付检查模块，适合给客户开通系统时逐项确认：

1. 企业资料已创建；
2. 企业账号已创建；
3. 服务期限已设置；
4. 设备已绑定；
5. 测试检测数据已生成；
6. 测试合格证已开具；
7. 打印流程已测试；
8. 客户使用信息已复制。

系统会根据已有账号、设备、检测记录、合格证和打印日志自动判断部分步骤是否完成。

## 企业使用概览

企业详情页业务概览增强，便于快速判断客户使用情况：

1. 企业账号数；
2. 绑定设备数；
3. 累计检测记录数；
4. 累计合格证数；
5. 正常合格证数；
6. 作废合格证数；
7. 累计打印次数；
8. 最近登录时间；
9. 最近检测时间；
10. 最近开证时间。

## 客户服务备注

企业详情页新增客户服务备注，只在后台显示，不展示给客户和扫码公众页面。可记录：

1. 客户类型；
2. 售后注意事项；
3. 联系人补充信息；
4. 下次跟进事项。

## 厂家上传日志

新增“厂家上传日志”页面，用于后续检测仪真实对接时排查：

1. 是否收到了厂家上传；
2. 厂家编码是否正确；
3. 设备编号是否正确；
4. 设备是否绑定到企业；
5. 签名或数据格式是否有问题；
6. 是否重复上传。

日志页面不会显示厂家密钥、数据库异常堆栈或其他敏感信息。

## 帮助与说明

后台新增静态帮助页，覆盖客户开通、日常演示和问题排查。第一版不做复杂文档系统，便于快速查看。
