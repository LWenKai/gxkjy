# K329打印测试流程

## 测试目标

验证优博讯 K329 能否满足谷芯快检云 60×80mm 合格证标签打印场景。

## 测试前准备

1. K329 样机一台；
2. 60×80mm 标签纸；
3. 安卓手机或微信开发者工具真机调试环境；
4. 谷芯快检云小程序测试账号；
5. 一张正常合格证；
6. 厂家提供的 UNI-APP 蓝牙示例；
7. 厂家确认的蓝牙通信方式。

## 测试顺序

### 1. 设备基础检查

- 打印机可开机；
- 电量充足；
- 标签纸安装正确；
- 纸张类型设置为标签纸或间隙纸；
- 指令集可设置为 AUTO 或 TSPL；
- 自检页可正常打印。

### 2. 小程序扫描设备

- 打开小程序；
- 进入“我的 - 打印机管理”；
- 点击搜索设备；
- 确认能搜索到 K329；
- 记录设备显示名称。

注意：不向客户展示蓝牙 UUID、Service UUID、Characteristic UUID。

### 3. 连接测试

- 选择 K329；
- 点击连接；
- 确认连接成功；
- 断开连接；
- 再次连接；
- 确认重连稳定。

### 4. 文字打印测试

打印内容：

- 谷芯快检云；
- 农产品质量安全承诺达标合格证；
- 产品名称：西红柿；
- 数量：1 kg；
- 承诺主体：山西谷芯演示食品有限公司。

检查：

- 中文不乱码；
- 字体清晰；
- 不超出标签边界；
- 不出现重叠。

### 5. 二维码打印测试

打印一个合格证扫码链接二维码。

检查：

- 手机微信可扫码；
- 二维码清晰；
- 链接打开正常；
- 二维码位置不遮挡文字。

### 6. 60×80 标签完整测试

打印完整标签：

- 标题；
- 产品名称；
- 数量/单位；
- 产地；
- 承诺主体；
- 联系方式；
- 承诺依据；
- 检测结果；
- 开具时间；
- 合格证编号；
- 二维码。

检查：

- 标签内容完整；
- 重要信息清楚；
- 留白适中；
- 不裁切；
- 连续打印 3 张位置不漂移。

### 7. 状态测试

依次测试：

- 缺纸；
- 开盖；
- 低电量；
- 打印中；
- 连接断开；
- 打印失败重试。

用户提示应显示：

- 请装纸；
- 请关闭打印机盖；
- 打印机电量不足；
- 打印失败，请重新打印。

不要显示十六进制指令或厂家内部错误码。

### 8. 打印日志检查

打印后检查后台合格证详情：

- 打印时间；
- 打印机名称；
- 打印机型号；
- 连接方式；
- 操作人；
- 打印结果；
- 失败原因。

## 通过标准

1. 能扫描并连接 K329；
2. 中文打印正常；
3. 二维码可识别；
4. 60×80 标签完整；
5. 状态提示可读；
6. 打印日志完整；
7. 作废合格证不可打印；
8. 不影响模拟打印。
