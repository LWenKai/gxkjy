## 五、谷芯侧对接原则

1. 检测仪上传数据必须带 `manufacturer_code` 和 `device_sn`；
2. 谷芯后台提前把设备编号绑定到客户企业；
3. 系统通过 `manufacturer_code + device_sn` 判断数据归属；
4. 不依赖厂家上传的企业名称；
5. 不合格记录客户可见，但不能开具合格证；
6. 合格记录进入可开证列表；
7. 原始检测数值和上传日志需要保留，方便排查。
