# 第23步 系统完善与易用性增强记录

## 本次完善目标

本阶段不做官网、不接真实打印机、不接真实检测仪、不发布小程序，重点围绕现有管理后台、小程序端和扫码公开页做交付、售后、排查和日常使用体验增强。

## 管理后台新增内容

1. 企业详情新增“交付检查”模块，按企业资料、企业账号、服务期限、设备绑定、测试检测数据、测试合格证、打印流程、客户使用信息等步骤自动判断完成状态。
2. 企业详情业务概览增强，补充账号数、打印次数、最近登录、最近检测、最近开证、服务状态、到期天数等数据。
3. 企业详情新增“客户服务备注”，支持客户类型、服务备注、下次跟进，仅后台管理员可见。
4. 新增“厂家上传日志”页面，可按厂家编码、设备编号、处理状态、时间筛选，并支持 CSV 导出。
5. 新增“帮助与说明”页面，用于内部开通客户、日常演示和问题排查。

## 小程序端新增内容

1. 开具合格证页增加“常用产品”选择。
2. 支持将本次开证产品保存为常用产品。
3. 增加“复制上一张”能力，快速带入上一张合格证的产品、数量、单位、产地、承诺主体、联系方式、承诺依据、打印份数和备注。
4. 复制上一张时不会复制合格证编号、开具时间、扫码链接、作废状态；如果承诺依据为自行检测合格，仍需重新选择检测记录。
5. 新增开证成功页，提供打印合格证、复制扫码链接、查看开证记录、返回首页。

## 扫码页新增内容

1. 增加可信查询说明，明确查询结果由谷芯快检云实时生成，当前状态以页面显示为准。
2. 作废证书提示更清楚，说明不得继续作为有效流通凭证使用。
3. 增加截图保存、转发给采购方查看、实时状态为准的提示。

### admin 接口

1. `GET /api/admin/manufacturer-upload-logs`
2. `GET /api/admin/manufacturer-upload-logs/export`

### client 接口

1. `GET /api/client/products`
2. `POST /api/client/products`
3. `GET /api/client/certificates/latest`

### public 接口

未新增 public 接口，本次扫码页继续复用已有公开合格证接口和公开设置接口。

## 不影响内容

1. 不影响企业、设备、检测记录、合格证原有核心流程。
2. 不影响扫码公开页原有 token 查询逻辑。
3. 不影响真实打印机和检测仪后续对接。
4. 不重置数据库，不删除演示数据，不删除 uploads。
