# 检测仪数据上传接口字段说明

本文说明检测仪上传检测结果时建议使用的字段。当前用于厂家沟通和联调准备，不包含真实密钥。

## 一、接口基本信息

| 项目 | 内容 |
| --- | --- |
| 请求方式 | POST |
| Content-Type | application/json |
| 建议地址 | `https://api.gxkjy.com/api/open/detection/upload` |
| 认证方式 | HMAC-SHA256 签名 |
| 数据归属 | `manufacturer_code + device_sn` |

## 二、主字段

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| manufacturer_code | string | 是 | GXTEST | 厂家编码，由谷芯后台分配 |
| device_sn | string | 是 | GXDEMO001 | 设备编号，必须与后台绑定设备一致 |
| manufacturer_record_id | string | 是 | REC202607120001 | 厂家侧检测记录唯一 ID，用于防重复 |
| timestamp | number | 是 | 1783833600 | Unix 秒级时间戳 |
| nonce | string | 是 | abc123xyz | 随机字符串，防重放 |
| sign | string | 是 | 签名结果 | HMAC-SHA256 小写 hex |
| sample_name | string | 是 | 西红柿 | 样品名称 |
| product_name | string | 否 | 西红柿 | 产品名称，可与样品名称相同 |
| test_time | string | 是 | 2026-07-12 10:30:00 | 检测时间，建议北京时间 |
| result | string | 是 | qualified | 整条记录结论 |
| items | array | 是 | [] | 检测项目数组，至少 1 条 |

## 三、result 取值

| 值 | 含义 |
| --- | --- |
| qualified | 合格 |
| unqualified | 不合格 |
| unknown | 未知或无法判定 |

说明：不合格记录会进入客户检测记录，但不能用于开具合格证。

## 四、items 字段

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| item_name | string | 是 | 有机磷和氨基甲酸酯类农药残留 | 检测项目名称 |
| method | string | 否 | 酶抑制率法 | 检测方法 |
| value | string | 是 | 12.5 | 检测结果值 |
| unit | string | 否 | % | 单位 |
| limit_value | string | 否 | 50 | 限量值或判定阈值 |
| result | string | 是 | qualified | 单项结论 |
| conclusion | string | 否 | 合格 | 中文结论 |
| raw_value | string | 否 | 12.5 | 原始值 |
| reagent_batch | string | 否 | A20260701 | 试剂批号 |
| remark | string | 否 |  | 备注 |

## 五、签名字段

第一版建议只对以下核心字段签名：

1. manufacturer_code；
2. device_sn；
3. manufacturer_record_id；
4. timestamp；
5. nonce。

`sign` 不参与签名，`items` 暂不参与签名，避免 JSON 序列化差异导致厂家接入困难。
