# 谷芯快检云小程序端前端产品需求文档

## 1. 产品定位

谷芯快检云小程序面向食品安全快检场景，为企业客户提供检测记录查看、合格证开具、扫码链接查看、标签打印和企业资料管理入口。

本小程序不是后台管理工具，核心目标是让普通食品企业工作人员可以低学习成本完成“查看检测结果 -> 开具合格证 -> 打印/分享”的日常操作。

扫码公开页是合格证的对外展示页面，面向采购方、消费者、监管人员和合作客户，用于确认合格证状态、查看产品承诺信息、检测依据和企业公开资料。

## 2. 目标用户

### 2.1 小程序端用户

1. 食品加工企业工作人员；
2. 农产品合作社开证人员；
3. 配送企业、净菜企业操作人员；
4. 学校食堂、农贸市场等快检负责人；
5. 年龄偏大、非专业技术用户。

### 2.2 扫码公开页用户

1. 采购方；
2. 消费者；
3. 学校食堂、配送企业收货人员；
4. 农贸市场管理人员；
5. 监管或第三方查看人员；
6. 客户企业对外展示对象。

## 3. 核心使用场景

### 3.1 小程序端核心场景

| 场景 | 用户目标 |
|---|---|
| 登录系统 | 使用企业账号进入小程序 |
| 查看检测记录 | 查看今日或历史检测结果 |
| 开具合格证 | 选择合格检测记录或上传依据资料后生成合格证 |
| 管理常用产品 | 维护常开证产品，减少重复输入 |
| 查看合格证 | 查看已开证信息、扫码链接、状态 |
| 打印合格证 | 进入打印预览，连接打印设备后打印标签 |
| 我的页面 | 查看企业信息、服务期限、帮助、联系客服 |

### 3.2 扫码公开页核心场景

| 场景 | 用户目标 |
|---|---|
| 扫码查看合格证 | 确认证书是否有效 |
| 查看产品信息 | 了解产品名称、数量、产地、承诺主体 |
| 查看检测依据 | 查看检测记录或公开依据资料 |
| 查看企业公开资料 | 了解企业简介、图片、资质资料 |
| 识别作废证书 | 明确知道证书已作废，不能继续使用 |
| 无效链接访问 | 给出正式、清楚的无效提示 |

## 4. 全局导航

底部 Tab 建议保留 4 个：

| Tab | 作用 |
|---|---|
| 首页 | 工作台、核心数据、主要入口 |
| 检测 | 检测记录列表 |
| 开证 | 开具合格证主入口 |
| 我的 | 企业资料、产品、打印机、帮助 |

所有二级页面必须有清晰返回按钮。若无上一页，则返回首页。

### 5.5 开具合格证页

模块：

1. 页面标题：开具合格证；
2. 承诺依据选择：
   - 自行检测合格；
   - 质量安全控制符合要求；

3. 检测记录选择区；

   - 产品名称；
   - 产品数量；
   - 单位；
   - 产地；
6. 承诺信息：
   - 承诺主体；
   - 联系电话；
   - 承诺事项；
7. 开证信息：
   - 开具时间；
   - 打印份数；
8. 生成合格证按钮。

规则：

1. 默认选择“自行检测合格”；
2. 自行检测合格必须选择一条合格检测记录；
3. 选择检测记录后自动带出产品名称、检测项目、检测时间；
4. 质量安全控制、委托检测必须上传图片或 PDF 依据资料；

6. 底部按钮不能透明，滚动内容不能透出；

## 6. 扫码公开页

### 6.1 页面定位

扫码公开页是合格证对外展示页面，不需要登录。用户通过扫描合格证二维码访问，用于确认合格证状态、查看产品承诺信息、检测依据和企业公开资料。

扫码页代表谷芯快检云和客户企业的外部形象，必须正式、可信、清楚，不能像后台页面，也不能暴露任何技术字段。

### 6.2 页面状态

扫码公开页至少包含三种状态：

| 状态 | 页面表现 |
|---|---|
| 正常有效 | 显示“查询有效”或“检测合格”，绿色可信状态 |
| 已作废 | 显示“该合格证已作废”，红/橙色警示状态 |
| 无效链接 | 显示“未查询到有效合格证”，不暴露技术错误 |

### 6.3 正常证书页面模块

#### 6.3.1 顶部可信查询区

内容：

1. 谷芯快检云；
2. 食品安全追溯查询；
3. 查询状态：查询有效；
4. 查询时间；
5. 合格证编号；
6. 状态大图标。

要求：

1. 状态图标要明显；
2. 第一眼能看出证书有效；
3. 不写“官方认证”“监管认证”等夸大描述；
4. 不显示接口、token、内部 ID。

#### 6.3.2 核心证书信息区

内容：

1. 合格证编号；
2. 产品名称；
3. 产品数量；
4. 单位；
5. 产地；
6. 承诺主体；
7. 联系方式；
8. 开具时间；
9. 证书状态。

要求：

1. 信息卡片化；
2. 重点信息突出；
3. 手机端阅读舒服；
4. 不做大表格堆叠。

#### 6.3.3 承诺信息区

内容：

1. 承诺依据；
2. 承诺事项；
3. 承诺主体；
4. 联系电话。

承诺依据类型：

1. 自行检测合格；
2. 质量安全控制符合要求；
3. 委托检测合格。

要求：

1. 语言让普通公众看得懂；
2. 不显示枚举值；
3. 不显示技术字段。

#### 6.3.4 检测结果区

当承诺依据为“自行检测合格”时展示。

内容：

1. 样品名称；
2. 检测时间；
3. 检测结论；
4. 检测项目列表。

检测项目每项显示：

1. 检测项目；
2. 检测值；
3. 单位；
4. 限量值；
5. 判定结果。

要求：

1. 卡片化展示；
2. 合格绿色；
3. 不合格红色；
4. 信息不要横向挤压；
5. 移动端不允许出现横向滚动；
6. 不显示设备编号、厂家编号。

#### 6.3.5 依据资料区

当承诺依据为“质量安全控制符合要求”或“委托检测合格”时展示公开资料。

内容：

1. 资料名称；
2. 文件类型；
3. 图片缩略图；
4. PDF/附件查看按钮；
5. 上传或更新时间，如有。

要求：

1. 只展示允许公开的资料；
2. 图片必须正确显示；
3. 图片可点击放大或打开；
4. PDF 可点击查看；
5. 不公开资料不显示；
6. 文件缺失时不要显示破图；
7. 不显示服务器真实路径。

#### 6.3.6 企业公开资料区

如果企业维护了公开资料，则展示。

内容：

1. 企业名称；
2. 企业简介；
3. 主营产品；
4. 展示地址；
5. 联系电话；
6. 资质说明；
7. 企业图片；
8. 企业 logo；
9. 公开 PDF 或附件。

要求：

1. 仅展示公开资料；
2. 图片可点开查看；
3. 图片显示失败时隐藏该图片或显示友好占位；
4. 附件显示为“查看资料”；
5. 不展示内部备注；
6. 不展示后台上传路径。

#### 6.3.7 查询说明区

建议文案：

“本查询结果由谷芯快检云实时生成，当前状态以本页面显示为准。”

“如显示查询有效，表示该合格证当前未作废，可用于查看产品承诺信息及相关检测/依据资料。”

要求：

1. 可信但不夸大；
2. 不写官方认证；
3. 不写监管认证。

#### 6.3.8 分享和保存提示

内容：

1. 可截图保存；
2. 可转发给采购方查看；
3. 查询结果以扫码页面实时状态为准。

### 6.4 作废证书页面模块

模块：

1. 顶部状态：该合格证已作废；
2. 作废说明；
3. 原合格证编号；
4. 产品名称；
5. 原开具时间；
6. 作废时间；
7. 技术支持信息。

作废提示文案：

“该合格证已作废，不得继续作为有效流通凭证使用。”

要求：

1. 视觉上明显区别正常证书；
2. 不让用户误以为仍有效；
3. 保留必要信息用于核对；
4. 不展示打印入口；
5. 不展示可误导的“合格有效”状态。

### 6.5 无效链接页面模块

模块：

1. 状态图标；
2. 标题：未查询到有效合格证；
3. 说明文案；
4. 技术支持信息。

建议文案：

“未查询到有效合格证，请核对二维码来源，或联系开具主体确认。”

要求：

1. 不显示 token；
2. 不显示接口错误；
3. 不显示 404、500 等技术错误；
4. 页面要正式，不要像报错页。

### 6.6 扫码页交互要求

1. 图片可点击预览；
2. PDF 可点击打开；
3. 外链或附件打开失败时提示“资料暂时无法打开”；
4. 页面刷新不报错；
5. 无数据模块自动隐藏；
6. 查询中显示加载状态；
7. 查询失败显示正式错误状态；
8. 手机端不横向滚动；
9. 长文本自动换行；
10. 所有按钮和链接要有足够点击区域。

### 6.7 扫码页空状态

| 模块 | 空状态处理 |
|---|---|
| 企业公开资料 | 无资料时整个模块隐藏 |
| 企业图片 | 无图片时不显示图片区 |
| 依据资料 | 无公开资料时显示“暂无公开依据资料”或隐藏 |
| 检测项目 | 无检测项目时显示“暂无检测项目明细” |
| 联系电话 | 无电话时隐藏该行 |
| 产地 | 无产地时隐藏或显示“未填写” |

### 6.8 扫码页加载状态

1. 首次进入显示“正在查询合格证信息”；
2. 加载完成后展示对应状态；
3. 加载失败显示“查询失败，请稍后重试”；
4. 不出现空白页；
5. 不出现接口返回原文。

### 6.9 扫码页适配要求

1. 以手机扫码访问为第一优先级；
2. 兼容微信内置浏览器、安卓浏览器、iOS Safari；
3. PC 访问时内容居中，宽度不宜过大；
4. 图片按比例裁剪，不拉伸变形；
5. 二维码来源页面打开速度要快；
6. 卡片间距舒适；
7. 字号适合公众阅读；
8. 状态区视觉足够醒目。

### 6.10 扫码页安全要求

扫码公开页不得展示：

1. public_token 字段名；
2. JWT；
3. API 地址；
4. debug 信息；
5. 设备编号；
6. 厂家编码；
7. access_secret；
8. 客户账号；
9. 后台地址；
10. 服务器路径；
11. 数据库字段名；
12. 内部备注；
13. 未公开资料。

## 9. 加载与错误状态

加载：

1. 页面首次进入显示加载状态；
2. 列表刷新显示轻量 loading；
3. 提交按钮显示“提交中”并防重复点击；
4. 扫码页首次进入显示“正在查询合格证信息”。

错误：

1. 网络异常：网络异常，请稍后重试；
2. 登录失败：登录失败，请检查账号或密码；
3. 开证失败：生成失败，请检查必填信息；
4. 打印份数错误：打印份数请输入 1-99；
5. 上传失败：文件上传失败，请检查格式和大小；
6. 服务到期：服务已到期，请联系谷芯科技续期；
7. 扫码查询失败：查询失败，请稍后重试。
