# 谷芯快检云全端视觉设计规范

## 设计关键词

科技感、高级感、食品安全、绿色健康、数据可信、简洁正式、专业可靠、适合普通客户使用。

## 色彩

- 主色：深绿色和青绿色，用于主按钮、有效状态、核心品牌区域。
- 辅助色：深蓝、青色，用于科技感渐变和辅助信息。
- 背景色：浅灰绿、浅蓝灰，保持清爽和专业。
- 卡片色：白色或轻微渐变白，避免纯灰旧系统观感。
- 成功状态：绿色。
- 警示状态：橙色。
- 危险状态：红色。

## 圆角和阴影

- 后台卡片建议 14-22px 圆角。
- 小程序卡片建议 24-34rpx 圆角。
- 扫码页卡片建议 18px 圆角。
- 阴影应轻量，突出层级，不做厚重漂浮感。

## 布局

- 页面主体不能固定死宽度导致溢出。
- 搜索区在窄屏自动换行。
- 表格操作按钮不能挤压核心字段。
- 长文本应省略或换行，不撑破布局。
- 详情页使用分区卡片。
- 小程序表单应分组，不使用一长串压迫式字段。

## 字号

- 标题突出但不夸张。
- 小程序按钮和表单字号要适合现场操作。
- 扫码公开页字号优先照顾手机阅读。

## 组件规则

- 主按钮使用绿色或绿青渐变。
- 次按钮使用浅绿底或白底绿边。
- 作废、删除、危险操作必须弱化并二次确认。
- 状态标签必须一眼可辨，不直接显示枚举值。
- 空状态使用中文说明，不显示技术错误。
- 加载失败提示应温和、明确。

## 三端一致性

- 后台管理端偏正式 SaaS 管理系统。
- 小程序端偏大按钮、大卡片、少字段、易操作。
- 扫码公开页偏可信查询和公开证明展示。
- 三端共用绿色、青色、浅灰绿、卡片白底、圆角阴影体系。
