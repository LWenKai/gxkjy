# 谷芯快检云正式测试环境运维说明

## 服务器信息

- 公网 IP：182.92.75.122
- 系统：Ubuntu 22.04
- 部署目录：`/opt/gxkjy`
- 访问入口：
  - API：https://api.gxkjy.com
  - 管理后台：https://admin.gxkjy.com
  - 扫码公开页：https://cert.gxkjy.com

## Docker 容器

当前主要容器：

- `mysql`：MySQL 数据库
- `backend`：后端 API
- `admin-web`：管理后台静态页面
- `public-h5`：扫码公开页静态页面
- `nginx`：统一反向代理和 HTTPS

查看容器状态：

```bash
cd /opt/gxkjy
docker compose -f deploy/docker-compose.yml ps
```

## Nginx

Nginx 负责：

- `api.gxkjy.com` 转发到后端 API
- `admin.gxkjy.com` 访问管理后台
- `cert.gxkjy.com` 访问扫码公开页
- HTTP 自动跳转 HTTPS

查看 Nginx 日志：

```bash
cd /opt/gxkjy
docker compose -f deploy/docker-compose.yml logs --tail=100 nginx
```

## HTTPS 证书

当前使用 Let’s Encrypt 证书，覆盖：

- `api.gxkjy.com`
- `admin.gxkjy.com`
- `cert.gxkjy.com`

检查证书到期：

```bash
pnpm cert:check
```

服务器上也可以查看：

```bash
certbot certificates
systemctl list-timers | grep certbot
```

手动续期检查：

```bash
certbot renew --dry-run
```

证书续期后，如 Nginx 未自动加载，可重启 Nginx 容器：

```bash
cd /opt/gxkjy
docker compose -f deploy/docker-compose.yml restart nginx
```

## 数据库备份

备份脚本路径：

```bash
/opt/gxkjy/deploy/backup/backup-mysql.sh
```

手动执行备份：

```bash
cd /opt/gxkjy
bash deploy/backup/backup-mysql.sh
```

备份文件会生成到服务器配置的备份目录，文件名带日期时间。恢复前必须先确认目标数据库和备份文件，避免覆盖有效数据。

## 冒烟测试

在项目目录执行：

```bash
pnpm smoke:https
```

脚本会检查：

- API 健康检查
- 公开设置接口
- 管理后台首页状态
- 正常、作废、无效扫码页
- demo 客户登录
- 客户首页、检测记录、合格证接口

## 常见问题

### 管理后台打不开

1. 检查域名是否解析到服务器。
2. 检查 Nginx 容器是否运行。
3. 检查 HTTPS 证书是否有效。
4. 查看 Nginx 日志。

### API 返回异常

1. 查看 `/api/health`。
2. 检查 backend 容器状态。
3. 查看 backend 日志。
4. 确认 MySQL 容器为 healthy。

### 扫码页打不开

1. 检查 `cert.gxkjy.com` 是否可访问。
2. 确认公开页路径为 `/c/{publicToken}`。
3. 测试 `/c/invalid-token` 是否能打开。

## 回滚说明

- Nginx 配置异常：恢复部署前备份的 Nginx 配置后重启 Nginx。
- `.env` 地址配置异常：恢复部署前备份的 `.env` 文件，权限保持 `600`，然后重建相关容器。
- 后端新版本异常：回退到上一版代码后重新构建 backend。
- 管理后台新版本异常：回退到上一版代码后重新构建 admin-web。

回滚时不要删除数据库，不要重置数据，不要开放 3306 或 3000 到公网。
