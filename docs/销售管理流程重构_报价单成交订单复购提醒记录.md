# 销售管理流程重构：报价单、成交订单与复购提醒

## 本次目标

本次将谷芯快检云后台销售管理从“简版报价 + 手工采购记录”调整为更接近真实销售使用的闭环：

新增客户 -> 记录需求/设备/跟进 -> 从销售产品库选择产品生成正式报价单 -> 保留报价版本 -> 客户确认 -> 报价转成交订单 -> 按订单产品明细设置复购提醒 -> 到期生成复购报价。

## 主要改动

1. 新增正式报价单体系，保留原有简版报价记录。
2. 报价单支持产品明细、版本号、商务条款、PDF、Excel。
3. 报价生成正式文件后不可直接覆盖修改，需创建新版本。
4. 已确认报价可直接转为成交订单，不再要求重复录入同样产品和金额。
5. 成交订单明细增加是否提醒、实际周期、提前提醒天数、预计补货日期。
6. 复购提醒基于订单产品明细，不再基于整张订单。
7. 销售产品库的复购周期调整为“参考周期”，仅作为录入订单时建议。

## 报价文件

PDF 和 Excel 由后端生成，保存到：

`uploads/sales-quotes/{customerId}/{quoteId}/`

文件下载必须后台登录，不通过公开静态路径暴露。

报价单固定显示：

- 山西谷芯科技有限公司
- 联系电话：13363412262
- 公司地址：山西省太原市万柏林区迎泽世纪城A座810

不显示税号、开户行、银行账号和营业执照。

## 安全边界

本模块只开放给后台超级管理员。

不影响：

- 客户企业端
- 小程序端
- 扫码公开页
- 检测记录
- 合格证流程
- 厂家数据接口

不向公开接口返回采购成本、内部备注、服务器文件路径或报价文件真实路径。

## 测试要点

1. 新建报价，选择多个销售产品，保存草稿。
2. 生成 PDF 和 Excel，下载文件。
3. 创建 V2 版本，确认 V1 不被覆盖。
4. 标记报价已接受，转为成交订单。
5. 成交订单中按产品设置不同复购周期。
6. 复购提醒页能看到待提醒项。
7. 从复购提醒生成新报价。
8. 未登录下载报价文件应返回 401。
