# 第20B步 系统真实使用体验优化记录

## 一、本次目标

本阶段围绕第一批客户试用前的真实使用问题做收口优化，不接真实检测仪、不接真实打印机、不发布微信小程序，不重置数据库，不删除演示数据和 uploads。

## 二、修复问题列表

1. 企业公开资料上传后列表展示不清楚、页面存在乱码。
   - 重写后台企业公开资料页面。
   - 上传后立即刷新列表。
   - 列表展示文件名称、资料类型、大小、上传时间、排序和公开状态。
   - 支持查看、编辑名称和类型、修改排序、公开/隐藏、删除。
   - 后端删除改为只写入 `deleted_at` 并关闭公开状态，不再物理删除本地文件。

2. 产品库录入体验差、错误提示不友好。
   - 重写后台产品库页面。
   - 新增/编辑时只强制“所属企业”和“产品名称”。
   - 分类、单位、规格、产地、备注为可选。
   - 后端新增产品 DTO 增加中文校验提示。
   - 导出前增加确认弹窗，说明导出范围、数量和 CSV 格式。

3. 厂家接口字段不清楚。
   - 厂家编码改为服务端自动生成，格式为 `MFR` + 6 位数字。
   - 前端不再要求手填厂家编码。
   - 接入密钥默认隐藏，列表只显示“已生成”。
   - 增加重新生成密钥接口和前端按钮。
   - IP 白名单增加说明，允许为空。

4. 检测记录操作栏拥挤，状态无法恢复。
   - 重写检测记录页面。
   - 操作改为“查看 + 更多操作”。
   - 新增恢复接口：恢复正常、取消异常。
   - 隐藏、异常、作废、恢复操作均可填写原因，并写入操作日志。
   - 不可开证原因用中文展示。

5. 厂家上传日志页面空数据和筛选体验差。
   - 重写厂家上传日志页面。
   - 无数据展示“暂无上传记录”。
   - 搜索区统一为厂家、设备、时间、状态。
   - 导出前增加确认。

6. 操作日志页面空数据和筛选体验差。
   - 重写操作日志页面。
   - 无数据展示“暂无操作记录”。
   - 列表展示时间、操作人、模块、动作、结果/摘要。
   - 导出前增加确认。

7. 后台小程序预览页不再需要。
   - 移除 `/miniapp-preview` 路由。
   - 移除后台菜单入口。
   - 删除前端预览页面和对应前端 API 文件。
   - 不影响真实小程序构建和运行。

8. 小程序登录体验。
   - 重写小程序登录页。
   - 登录成功保存账号，下一次自动填充账号。
   - 不保存明文密码。
   - 登录成功、登录失败、网络异常改为正常中文提示。
   - 我的页面增加“清除已保存账号”。
