# 承诺达标合格证字段与承诺依据设计说明

## 合格证核心字段

农产品质量安全承诺达标合格证至少包含：

1. 承诺事项
2. 承诺依据
3. 产品名称
4. 产品数量/重量
5. 产地
6. 承诺主体
7. 联系方式
8. 开具时间

## 承诺依据

第一版支持三种承诺依据，默认选中“自行检测合格”。

### 自行检测合格

必须选择一条本企业合格且状态正常的检测记录。合格证与该检测记录建立关联，扫码公开页展示检测记录摘要和检测项目明细。

### 质量安全控制符合要求

不强制选择系统检测记录，但必须上传至少一份质量控制相关资料。资料用于开证依据留存，默认不公开展示。

### 委托检测合格

不强制选择系统检测记录，但必须上传委托检测报告或相关证明。默认允许公开展示，扫码公开页可展示公开依据资料。

## 不公开内容

扫码公开页不展示客户账号、设备编号、厂家编码、后台日志、密钥、JWT、数据库信息等内部字段。
