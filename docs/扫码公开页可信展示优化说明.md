# 扫码公开页可信展示优化说明

扫码公开页面向采购方、公众和客户扫码查看，是系统可信展示的重要入口。

## 查询状态

页面会清楚展示：

1. 查询有效；
2. 合格证已作废；
3. 未查询到对应合格证信息。

作废页面会提示该合格证不得继续作为有效流通凭证使用。

## 可信说明

页面新增说明：

本查询结果由谷芯快检云实时生成，当前状态以本页面显示为准。

显示“查询有效”表示该合格证当前未作废，可用于查看产品承诺信息及相关检测/依据资料。

## 企业公开资料

扫码页只展示企业设置为公开的资料：

1. 企业简介；
2. 企业图片；
3. 资质图片；
4. PDF 等公开附件。

非公开资料不会展示，本地服务器真实路径不会展示。

## 检测项目

自行检测合格作为承诺依据时，页面展示检测项目、检测值、单位、限量值和判定结果。

## 查看提示

页面增加提示：可截图保存，也可转发给采购方查看，查询结果以扫码页面实时状态为准。
