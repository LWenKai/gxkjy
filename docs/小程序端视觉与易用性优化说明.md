# 小程序端视觉与易用性优化说明

## 目标用户

食品加工企业、农产品合作社、配送企业、学校食堂、市场管理方、检测员和开证员。

## 本次优化

- 登录页增强品牌识别和正式感。
- 首页改为客户工作台风格，核心数据和入口更突出。
- 开具合格证页将承诺依据、依据资料、开证信息、承诺事项分区展示。
- 合格证详情更像正式电子凭证。
- 打印机连接页明确当前是模拟打印。
- 打印预览页强化 60×80mm 标签感。
- 全局按钮、卡片、标签、输入框统一视觉。

## 易用性原则

- 大按钮、大卡片、清楚文案。
- 少技术词，不展示内部字段。
- 返回按钮清晰。
- 成功、失败、不可操作状态用中文解释。
- 不把作废、打印等重要操作做得过于随意。

## 当前边界

真实蓝牙打印、真实检测仪器、小程序发布仍未接入或执行。
