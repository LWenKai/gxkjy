# 厂家资料包说明

## 一、明天发给检测仪厂家的文件

建议发送：

1. `检测仪对接/谷芯快检云检测仪数据对接说明_厂家版.docx`
2. `检测仪对接/检测仪厂家资料确认清单.docx`
3. `检测仪对接/检测仪上传接口curl测试示例.md`

发送顺序：

1. 先发微信话术简短版；
2. 对方愿意转技术后，发送厂家版对接说明和资料确认清单；
3. 对方技术需要看请求格式时，再发送 curl 测试示例；
4. 厂家回复后，把信息记录到 `检测仪厂家回复信息登记表.docx`。

## 二、明天发给打印机厂家的文件

建议发送：

1. `打印机对接/打印机对接资料确认清单.docx`
2. `打印机对接/真实打印机对接技术方案草案.docx`

发送顺序：

1. 先发微信话术简短版；
2. 对方确认能转技术后，发送资料确认清单；
3. 技术需要判断接入路线时，发送真实打印机对接技术方案草案；
4. 厂家回复后，把信息记录到 `打印机厂家回复信息登记表.docx`。

## 三、对外和内部文件区分

对外可发：

1. 检测仪厂家版对接说明；
2. 检测仪厂家资料确认清单；
3. 检测仪上传接口 curl 测试示例；
4. 打印机对接资料确认清单；
5. 真实打印机对接技术方案草案；
6. 两份微信话术。

内部使用：

1. 检测仪厂家回复信息登记表；
2. 打印机厂家回复信息登记表；
3. 项目内部联调操作手册。

## 四、安全注意

1. 不要给厂家发送真实服务器密码；
2. 不要给厂家发送数据库密码；
3. 不要给厂家发送 JWT_SECRET；
4. 不要给厂家发送 OSS_SECRET；
5. 不要在微信群里发送真实 access_secret；
6. 如需给厂家测试密钥，单独通过安全渠道发送，并记录给了谁。
