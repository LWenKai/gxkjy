# 真实打印机对接技术方案草案

本文是打印机真实接入前的技术方案草案。当前系统不调用真实蓝牙、不接厂家 SDK、不发布小程序，只保留模拟打印和打印日志。

## 一、目标

将谷芯快检云小程序中的合格证标签，从“模拟打印”升级为“真实打印”。

真实打印成功后，需要做到：

1. 用户在合格证详情或打印预览页点击打印；
2. 系统检查打印机连接状态；
3. 生成 60×80mm 标签内容；
4. 调用打印适配器；
5. 打印成功或失败后记录日志；
6. 用户能看到清楚的错误提示。

## 二、当前已准备的代码结构

已新增 `packages/print-core`，用于放置通用打印模型：

1. `PrinterAdapter`：打印适配器接口；
2. `MockPrinterAdapter`：模拟打印适配器；
3. `CertificatePrintPayload`：合格证打印数据；
4. `CertificateLabelTemplate`：60×80mm 标签模板结构；
5. `createPrintJob`：生成打印任务；
6. `buildCertificateLabel`：生成标签内容。

该结构不依赖微信小程序、蓝牙或厂家 SDK，后续可以按真实方案接入。

## 三、可选接入路线

### 方案 A：厂家小程序 SDK

适用情况：

1. 厂家明确支持微信小程序；
2. 厂家提供 SDK 和示例；
3. SDK 能连接打印机并下发打印任务；
4. 能返回打印状态。

优点：接入相对稳定，少处理底层指令。

风险：SDK 质量、授权方式、微信兼容性需要验证。

### 方案 B：蓝牙指令打印

适用情况：

1. 厂家提供 ESC/POS、TSPL、CPCL 等指令；
2. 小程序可使用蓝牙能力；
3. 标签内容可转换为指令。

优点：不强依赖厂家 SDK。

风险：中文、二维码、图片、断线重连、不同机型兼容需要大量测试。

### 方案 C：图片打印

适用情况：

1. 打印机支持图片打印；
2. 小程序能生成标签图片；
3. 厂家 SDK 或指令支持图片下发。

优点：标签样式最可控。

风险：图片生成、尺寸、清晰度和打印速度需要测试。

### 方案 D：Android App 或专用终端打印

适用情况：

1. 微信小程序无法直接稳定打印；
2. 打印机需要 Android SDK；
3. 需要在安卓终端上完成打印。

优点：硬件能力更完整。

风险：需要额外 App 或终端，交付链路变长。

## 四、建议判断顺序

明天拿到厂家资料后，建议按以下顺序判断：

1. 是否有微信小程序 SDK；
2. 是否支持 60×80mm 标签和二维码；
3. 是否能提供完整示例；
4. 是否能返回打印状态；
5. 如果没有 SDK，是否有蓝牙指令文档；
6. 如果蓝牙复杂，是否支持图片打印；
7. 如果小程序无法稳定打印，再评估 Android App 或换打印机。

## 五、打印日志规则

后端已有 `certificate_print_logs` 表，真实打印接入后建议记录：

1. 合格证 ID；
2. 打印端：miniapp/admin/system；
3. 适配器类型：mock/vendor_sdk/bluetooth_command/image；
4. 打印状态：success/failed/simulated；
5. 打印份数；
6. 错误原因；
7. 打印时间。

不记录厂家密钥、蓝牙配对密钥或用户密码。

## 六、当前不得做的事

1. 不调用真实蓝牙；
2. 不接优博讯 SDK；
3. 不写死某个打印机型号；
4. 不申请微信蓝牙权限；
5. 不发布小程序；
6. 不上传体验版。

## 七、联调验收标准

真实打印接入完成后，至少要验证：

1. 首次连接打印机；
2. 断开后重连；
3. 打印正常合格证；
4. 作废合格证不可打印；
5. 打印 1 份和多份；
6. 缺纸、断连等错误提示；
7. 打印日志记录；
8. 二维码扫码能打开合格证公开页。
