# 扫码公开页视觉与可信展示说明

## 页面定位

扫码公开页面向采购方、监管人员、消费者和客户，用于查看合格证状态、产品信息、承诺依据、检测记录或公开依据资料。

## 本次优化

- 顶部增加“可信扫码查询”视觉区。
- 正常证书突出“查询有效”。
- 作废证书突出“合格证已作废”。
- 无效链接显示正式的无效状态，不展示假数据。
- 合格证编号独立高亮，便于核对。
- 产品信息、承诺信息、检测结果、企业资料分区展示。
- 底部保留谷芯快检云技术支持和风险说明。

## 安全展示规则

公开页不展示设备编号、厂家编码、客户账号、密钥、后台内部字段、JWT、public_token 字段名。

## 当前边界

公开页展示的是企业快检和合格证信息，不等同于第三方检验检测机构报告。
