# 谷芯快检云第一阶段测试用例

## 基础启动

- 后端健康检查返回 `status: ok`。
- 后端健康检查返回 `database: ok`。
- 管理后台页面可以打开。
- 扫码公开页页面可以打开。
- 微信小程序可以编译到微信小程序目标。

## 第 1 步：后端基础链路

- Prisma migration 可成功创建全部核心表。
- seed 可初始化后台超级管理员 `admin`。
- 重复执行 seed 不会重复创建 `admin`。
- `POST /api/admin/auth/login` 可使用 `admin / Guxin@2026` 登录。
- 登录成功返回 `access_token`。
- 登录响应不包含 `password_hash`。
- 错误密码登录失败，返回 `INVALID_CREDENTIALS`。

## 第 2 步：后台基础业务 API

### 鉴权

- 不带 `Authorization` 访问 `/api/admin/companies`，返回 `401` 和 `UNAUTHORIZED`。
- 带有效管理员 token 可访问后台业务接口。
- 无效 token 访问后台业务接口失败。
- 第一版只校验超级管理员登录，不做复杂权限。

### 企业管理

- 带 token 新增企业成功，必填字段为 `name`、`contact_name`、`phone`、`service_expire_at`。
- 企业列表支持 `page`、`page_size`、`name`、`status`。
- 企业列表返回 `total`、`page`、`page_size`、`items`。
- 企业详情可查看。
- 企业可修改、启用、停用、续期。
- 企业不提供物理删除接口。

### 企业账号管理

- 可为指定企业创建企业账号。
- `username` 重复时创建失败。
- 密码使用 bcrypt 哈希存储。
- 不传初始密码时，接口返回一次性 `initial_password`。
- 账号列表响应不包含 `password_hash`。
- 企业账号可重置密码、启用、停用。

### 厂家接口管理

- 可新增厂家接口，`manufacturer_code` 唯一。
- 不传 `access_secret` 时，系统生成密钥并仅创建接口响应返回 `access_secret_once`。
- 厂家接口列表和详情不返回明文 `access_secret`，只返回 `access_secret_masked`。
- 厂家接口可修改、启用、停用。

### 设备管理

- 可新增未绑定企业的设备。
- `manufacturer_code + device_sn` 重复时创建失败。
- 可将设备绑定到企业，也可解绑。
- 设备列表支持 `company_id`、`manufacturer_code`、`status`。
- 设备可修改、启用、停用。
- 设备不提供物理删除接口。

### 操作日志

- 企业新增、修改、启停、续期写入 `operation_logs`。
- 企业账号创建、重置密码、启停写入 `operation_logs`。
- 厂家接口新增、修改、启停写入 `operation_logs`。
- 设备新增、修改、绑定、解绑、启停写入 `operation_logs`。

## 后续业务主流程预留

- 厂家接口使用测试厂家编码 `MFR001`。
- 测试设备使用 `GXTEST001`。
- 合格检测记录可开证。
- 不合格检测记录不可开证。
- 合格证生成后有唯一编号和随机 `public_token`。
- 扫码公开页能展示正常和已作废状态。
- 打印阶段只验证标签预览、模拟打印和打印日志。

## 第 5 步：合格证核心后端接口

- 后端 `build` 通过。
- 客户账号可以通过 `POST /api/client/auth/login` 登录。
- 企业停用后客户不能登录。
- 账号停用后客户不能登录。
- 企业服务到期后客户不能登录。
- 到期前 30 天登录返回 `expire_warning`。
- 后台可以通过 `POST /api/admin/test-detection-records` 生成测试合格检测记录。
- 后台可以生成测试不合格检测记录。
- 合格记录出现在 `/api/client/certifiable-records`。
- 不合格记录不出现在 `/api/client/certifiable-records`。
- 客户只能看到自己企业检测记录。
- 客户不能使用其他企业检测记录开证。
- 合格记录可以生成合格证。
- 不合格记录不能生成合格证。
- `hidden / voided / marked_abnormal` 检测记录不能开证。
- 合格证编号符合 `GX + YYYYMMDD + 6位日流水号`。
- `public_token` 随机且唯一，不使用数据库 ID 或合格证编号。
- 合格证可以作废。
- 作废后不能获取打印数据。
- 作废后原检测记录可以重新开证。
- `print-data` 返回 60×80mm 标签结构化数据。
- `print-logs` 可以记录模拟打印成功和失败。
- 后台可以查看检测记录和合格证。
- 后台不能物理删除检测记录和合格证。
- 所有关键操作写入 `operation_logs`。

## 第 7 步：扫码公开 H5 页面

- `GET /api/public/certificates/{publicToken}` 不需要登录即可访问。
- 使用正常合格证的 `public_token` 查询，返回 `valid=true`、`status=normal`。
- 正常合格证公开接口返回合格证信息、检测记录信息、检测项目明细、企业公开展示资料、技术支持和风险说明。
- 使用已作废合格证的 `public_token` 查询，返回 `status=voided`，并包含作废时间。
- 使用不存在的 `public_token` 查询，返回 `valid=false`、`status=invalid`，不返回假数据。
- 企业资料未开启公开时，不展示企业宣传资料模块。
- `file_assets.is_public=false` 的图片不展示。
- 公开接口响应中不包含 `device_sn`、`manufacturer_code`、客户账号、厂家密钥、后台操作日志、打印日志等内部字段。
- H5 `/c/{publicToken}` 可以读取 URL 中的 `publicToken` 并请求公开接口。
- 正常页面展示顶部品牌、检测合格状态、合格证信息、检测结果、企业信息、技术支持和风险说明。
- 已作废页面用明显的橙色/红色状态提示“该合格证已作废”，避免误认为证书仍有效。
- 无效链接页面显示“链接无效”，不跳转登录，不要求用户操作。
- H5 页面在 360px 到 430px 手机宽度下正常显示。
- H5 页面没有登录入口、真实检测上传功能、真实打印功能、蓝牙调用和小程序专属逻辑。

### 后台检测记录和合格证

- 后台检测记录列表可以按企业、检测结果和状态筛选。
- 检测记录详情可以查看检测项目明细。
- 标记异常、隐藏、作废记录均需要二次确认。
- 被标记异常、隐藏、作废的检测记录不能再开证。
- 后台合格证列表可以看到客户小程序生成的合格证。
- 合格证详情可以查看检测记录和检测项目明细。
- 公开链接可以复制和打开预览。
- 后台没有生成合格证、重新打印主按钮、删除合格证或真实打印功能。

### 服务状态和数据隔离

- 企业正常时客户可登录。
- 企业停用、服务到期、账号停用时客户不能登录。
- 到期前 30 天客户登录返回提醒。
- 设备停用后不影响已存在数据查看，但不能继续生成正式测试检测记录。
- 企业 A 客户只能访问企业 A 的检测记录和合格证。
- 企业 A 客户不能用企业 B 的检测记录开证。
- 公开 H5 只通过 public_token 暴露公开数据，不暴露后台信息。
