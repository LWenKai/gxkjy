# 第13步 管理后台功能补齐与样式优化记录

## 当前后台已有功能

- 后台管理员登录、JWT 鉴权、统一接口返回和错误处理。
- 企业管理：企业列表、新增、编辑、启用、停用、续期。
- 企业账号管理：创建账号、重置密码、启用、停用。
- 厂家接口管理：列表、新增、编辑、查看、启用、停用，列表不明文展示密钥。
- 设备管理：列表、新增、编辑、绑定企业、解绑、启用、停用。
- 检测记录管理：列表、详情、标记异常、隐藏、作废。
- 合格证管理：列表、详情、复制/查看公开链接、查看检测项目和打印日志。
- 测试检测记录后端接口：`POST /api/admin/test-detection-records`。
- 客户小程序、扫码公开 H5 依赖的客户侧和公开接口已具备。

## 当前后台缺失或不完整功能

- 后台首页仍是占位统计，不能反映真实数据库运行情况。
- 测试检测数据只有后端接口，后台缺少可操作页面。
- 操作日志只有写入能力，缺少后台查询页面和列表接口。
- 系统设置页面仍是占位，不能维护非敏感展示文案。
- 企业公开资料缺少后台维护入口，公开页虽然支持展示但不方便录入。
- 产品库表已存在，但字段不足且缺少后台管理页面。
- 后台整体样式偏基础，菜单结构和数据卡片需要整理。

## 本次实际补齐的功能

- 新增真实数据看板接口和页面：`GET /api/admin/dashboard/summary`。
- 新增测试检测数据录入页面：`/test-detection-records/create`。
- 新增操作日志列表接口和页面：`GET /api/admin/operation-logs`、`/operation-logs`。
- 新增系统设置接口和页面：`GET /api/admin/system-settings`、`PATCH /api/admin/system-settings`、`/settings`。
- 新增企业公开资料接口和页面：`/companies/:id/profile`，支持简介、电话、地址、主营产品、资质说明、公开开关和图片 URL 管理。
- 新增产品库接口和页面：`/products`，支持列表、新增、编辑、启用、停用和筛选。
- 调整后台菜单为：数据看板、企业管理、设备管理、厂家接口、检测记录、测试检测数据、合格证管理、产品库、操作日志、系统设置。
- 优化后台样式：菜单选中态、顶部标题、数据卡片、搜索区、表格头部、表单分栏、空状态和详情展示。

## 本次暂不做的功能及原因

- 不配置 `gxkjy.com`、HTTPS、微信小程序合法域名：当前域名实名认证仍在审核，本阶段继续使用临时 IP 测试。
- 不接真实检测仪器和真实厂家上传：需要厂家技术资料和设备联调，继续后置。
- 不接真实蓝牙打印和优博讯 K329 SDK：打印协议资料未确认，继续保留模拟打印。
- 不做文件上传和 OSS 真连接：当前只支持图片 URL 录入，避免在测试阶段上传或保存真实 OSS 密钥。
- 不做删除数据功能：第一版坚持软处理和启停，不做物理删除。
- 不做复杂权限、收费系统、统计大屏、Excel 导出和模板编辑器：超出第一版 MVP 范围。
