# 谷芯科技官网部署说明

## 部署形态

官网作为独立前端应用部署：

1. 源码目录：`website/`
2. Docker 服务：`website`
3. 容器名称：`guxin-website`
4. 宿主机绑定：`127.0.0.1:8083`
5. 对外入口：Nginx

## 当前已部署内容

1. `website` 服务已加入 Docker Compose。
2. Nginx 已增加 `www.gxkjy.com` 和 `gxkjy.com` 的 HTTP server block。
3. 官网容器已在 ECS 上运行。
4. 当前因 DNS 未解析，公网域名暂不能直接访问官网。

## 域名规划

主域名：

`https://www.gxkjy.com`

可选根域名：

`https://gxkjy.com`

建议根域名后续跳转到 `www.gxkjy.com`，保持对外入口统一。

## DNS 配置

需要在阿里云域名解析中添加：

1. `www.gxkjy.com` A 记录 -> `182.92.75.122`
2. `gxkjy.com` A 记录 -> `182.92.75.122`

## HTTPS 配置

DNS 生效后，使用 Let’s Encrypt 申请证书。

建议证书包含：

1. `www.gxkjy.com`
2. `gxkjy.com`

证书完成后再配置：

1. HTTP 自动跳转 HTTPS。
2. `gxkjy.com` 跳转到 `www.gxkjy.com`。

## 不影响现有系统

官网部署不改变：

1. `api.gxkjy.com`
2. `admin.gxkjy.com`
3. `cert.gxkjy.com`
4. MySQL 端口策略
5. backend 端口策略
6. uploads 文件目录

## 验证方式

DNS 未解析前，可在服务器本机通过 Host 头验证官网服务：

`curl -H 'Host: www.gxkjy.com' http://127.0.0.1/`

DNS 生效后再验证：

`https://www.gxkjy.com`
