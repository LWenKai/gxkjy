# 谷芯快检云后台管理员操作说明_临时测试版

> 本说明适用于当前临时 IP 测试环境。后台地址：`http://182.92.75.122/admin/`

## 1. 登录后台

做什么：

- 进入谷芯快检云管理后台，进行企业、设备、检测记录和合格证管理。

怎么做：

1. 打开 `http://182.92.75.122/admin/`。
2. 输入管理员账号和密码。
3. 点击“登录”。

注意：

- 当前为临时测试环境。
- 正式部署前必须修改默认管理员密码。
- 不要在客户现场公开展示管理员密码。

## 2. 查看数据看板

做什么：

- 快速了解当前测试环境中的企业、设备、检测记录和合格证数据。

怎么做：

1. 登录后进入“数据看板”。
2. 查看企业总数、设备总数、检测记录、合格证数量等数据。
3. 查看最近检测记录和最近合格证。

注意：

- 看板数据来自系统真实数据，不是静态假数据。
- 没有数据时会显示 0 或空状态。

## 3. 新增企业

做什么：

- 为客户企业开户，建立企业基础资料。

怎么做：

1. 进入“企业管理”。
2. 点击“新增企业”。
3. 填写企业名称、联系人、联系电话、地址、产地/基地地址、服务有效期。
4. 选择默认合格证类型。
5. 保存。

注意：

- 企业名称、联系人、联系电话建议填写完整。
- 服务到期后客户账号不能登录。
- 不提供删除企业功能，如不再使用可停用企业。

## 4. 维护企业账号

做什么：

- 给企业客户创建登录账号，让客户在移动端查看检测记录、开具合格证。

怎么做：

1. 进入“企业管理”。
2. 点击企业列表中的“查看”。
3. 在企业详情中找到“企业账号”区域。
4. 点击新增账号，填写登录账号、姓名和初始密码。
5. 如客户忘记密码，可点击“重置密码”。
6. 如账号暂停使用，可点击“停用”。

注意：

- 不显示账号密码明文。
- 重置后的临时密码只展示一次，请及时告知客户。
- 第一版不做复杂角色权限。

## 5. 维护企业公开资料

做什么：

- 设置扫码公开页中展示的企业简介、主营产品、联系电话、公开图片等信息。

怎么做：

1. 进入“企业管理”。
2. 打开企业详情。
3. 进入“公开资料”入口。
4. 填写企业简介、主营产品、展示地址、展示电话、资质说明。
5. 打开“启用公开展示”。
6. 如需展示图片，可录入图片名称、图片 URL、图片类型，并设置为公开。
7. 保存。

注意：

- 当前测试阶段不做真实文件上传，只支持图片 URL 录入。
- 只有开启企业公开展示后，扫码公开页才显示企业公开资料。
- 只有设置为公开的图片才会展示。

## 6. 新增厂家接口

做什么：

- 维护检测仪器厂家基础配置，为后续真实仪器对接做准备。

怎么做：

1. 进入“厂家接口”。
2. 点击“新增厂家接口”。
3. 填写厂家名称、厂家编码、对接方式、签名规则等信息。
4. 保存并启用。

注意：

- 当前只是维护基础配置，不做真实仪器联调。
- 页面不明文展示厂家密钥。
- 不提供删除厂家接口功能，如暂不使用可停用。

## 7. 新增设备

做什么：

- 维护检测设备信息，并绑定到客户企业。

怎么做：

1. 进入“设备管理”。
2. 点击“新增设备”。
3. 填写厂家编码、设备编号、设备名称、型号。
4. 保存。

注意：

- 设备可以先创建，再绑定企业。
- 设备编号要与后续真实设备上传时保持一致。
- 不提供删除设备功能，如暂不使用可停用。

## 8. 绑定设备到企业

做什么：

- 将设备归属到某个企业，使该企业后续能拥有对应检测记录。

怎么做：

1. 进入“设备管理”。
2. 找到设备，点击“绑定企业”。
3. 选择企业。
4. 确认绑定。

注意：

- 未绑定企业的设备，后续即使上传数据也不会进入正式检测记录。
- 当前测试环境使用测试设备生成演示检测记录。

## 9. 录入测试检测数据

做什么：

- 在没有真实检测仪器联调前，人工生成测试检测记录，用于演示客户开证流程。

怎么做：

1. 进入“测试检测数据”。
2. 选择企业。
3. 选择该企业已绑定设备。
4. 填写样品名称、样品类别。
5. 填写检测项目、检测值、单位、限量值和结论。
6. 如有多个检测项目，点击添加项目。
7. 点击提交。

注意：

- 该页面仅用于测试数据录入。
- 不代表真实检测仪器上传。
- 不合格检测记录不能开具合格证。

## 10. 查看检测记录

做什么：

- 查看所有企业的检测记录，辅助售后排查和数据核对。

怎么做：

1. 进入“检测记录”。
2. 可按企业、设备、检测结果、状态、日期筛选。
3. 点击详情查看检测项目明细。
4. 如发现问题，可标记异常、隐藏或作废。

注意：

- 后台不支持手动新增真实检测记录。
- 后台不支持物理删除检测记录。
- 被标记异常、隐藏或作废的记录不能用于开证。

## 11. 管理合格证

做什么：

- 查看客户已开具的合格证，复制公开链接，核对对应检测记录。

怎么做：

1. 进入“合格证管理”。
2. 可按企业、产品、状态、日期筛选。
3. 点击详情查看合格证信息和对应检测结果。
4. 复制公开链接，用浏览器打开查看扫码页。

注意：

- 后台不作为主要重新打印入口。
- 后台不生成合格证。
- 后台不删除合格证。
- 重新打印和作废主要由客户移动端完成。

## 12. 管理产品库

做什么：

- 维护企业常用产品资料，为后续检测和开证提供基础信息。

怎么做：

1. 进入“产品库”。
2. 点击新增产品。
3. 选择企业，填写产品名称、类别、规格、产地、默认单位。
4. 保存。
5. 如产品暂不使用，可停用。

注意：

- 第一版产品库不做库存、价格、采购销售管理。
- 产品库只是基础资料。

## 13. 查看操作日志

做什么：

- 查看后台重要操作记录，便于追踪是谁在什么时候做了什么。

怎么做：

1. 进入“操作日志”。
2. 可按操作人、模块、操作类型、时间筛选。
3. 查看操作摘要和 IP 信息。

注意：

- 操作日志只读。
- 不允许删除或编辑日志。
- 日志中不展示密码、密钥和 token。

## 14. 修改系统设置

做什么：

- 维护公开页展示文案、服务电话、技术支持说明等非敏感配置。

怎么做：

1. 进入“系统设置”。
2. 修改平台名称、服务电话、技术支持说明、公开页底部说明等内容。
3. 保存。

注意：

- 不要在系统设置里填写数据库密码、服务器密码、密钥等敏感信息。
- 敏感配置只能放在服务器环境变量中。

## 15. 常见问题说明

### 客户登录不了怎么办？

- 检查企业是否停用。
- 检查企业服务是否到期。
- 检查客户账号是否停用。
- 如忘记密码，可在企业详情中重置密码。

### 为什么检测记录不能开证？

- 检测结果不合格。
- 检测记录被隐藏、作废或标记异常。
- 记录不属于当前客户企业。

### 为什么扫码页不显示企业资料？

- 企业公开资料未开启。
- 企业资料未填写。
- 图片未设置为公开。

### 为什么不能真实打印？

- 当前为模拟打印。
- 真实打印需要等待打印机 SDK 或协议资料确认后接入。
