# 谷芯快检云小程序 V2 视觉规范与页面还原清单

## 一、目标

本轮小程序 V2 的目标不是增加新功能，而是把现有客户端界面统一成正式、清爽、可信的食品安全 SaaS 小程序。

第一版以首页和我的页为视觉基准，后续二级、三级页面都按同一套组件语言收口。

## 二、设计原则

1. 只保留客户日常高频操作，不在首页堆功能。
2. 页面以白底、浅绿背景、绿色主按钮为主。
3. 卡片圆角统一，阴影轻，不使用重渐变和花哨装饰。
4. 所有按钮文案要短，客户一眼能看懂。
5. 所有客户可见文案必须是简体中文，不允许乱码、英文异常、接口错误。
6. 二级页尽量依赖微信原生返回和左滑返回，不重复放无意义返回按钮。

| 组件 | 规范 |
| --- | --- |
| 页面背景 | 浅绿色或近白背景 |
