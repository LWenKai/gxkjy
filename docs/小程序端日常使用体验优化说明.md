# 小程序端日常使用体验优化说明

本次小程序端围绕“少重复填写、开证后下一步更明确”做增强。

## 常用产品

开具合格证页面支持从常用产品中快速选择产品名称、默认单位和默认产地。

如果客户暂无常用产品，页面会提示本次开证时可保存为常用产品。

## 保存为常用产品

客户开证时可勾选“保存为常用产品”。生成合格证后，系统会保存产品名称、默认单位和产地，方便下次使用。

## 复制上一张

“复制上一张”会带入上一张正常合格证中的常用字段：

1. 产品名称；
2. 产品数量和单位；
3. 产地；
4. 承诺主体；
5. 联系方式；
6. 承诺依据；
7. 打印份数；
8. 备注。

不会复制：

1. 合格证编号；
2. 开具时间；
3. 扫码链接；
4. 作废状态；
5. 旧检测记录。

如果承诺依据是“自行检测合格”，复制后仍必须重新选择新的合格检测记录。

## 开证成功页

生成合格证后进入成功页，客户可以直接：

1. 打印合格证；
2. 复制扫码链接；
3. 查看开证记录；
4. 返回首页。

当前打印仍为模拟打印，真实打印机接入后再启用真实打印。
