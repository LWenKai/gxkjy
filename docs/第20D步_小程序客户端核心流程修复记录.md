# 第20D步 小程序客户端核心流程修复记录

## 一、修复目标

本次重点恢复客户小程序真实使用闭环：

登录 → 首页 → 检测记录 → 开具合格证 → 合格证详情 → 打印预览 → 我的。

本阶段不接真实检测仪、不改厂家接口、不发布小程序、不上传体验版。

## 二、问题原因

1. 小程序多个源码文件出现中文乱码、字符串和标签损坏，导致页面可能编译失败或运行白屏。
2. “我的”页面过度依赖本地缓存，且模板存在损坏标签，进入页面容易空白。
3. 检测详情进入开证页时使用 tabBar 页面 query 跳转，微信小程序 tabBar 页面不适合依赖 query 传参。
4. 开证页未稳定按检测记录 ID 拉取详情，导致选择检测记录后不能展示检测信息。
5. 部分页面缺少 loading、空状态、错误状态，接口失败时体验不清楚。

## 三、修复内容

### 0. 真机白屏补丁

- 真机报错：`module 'print/printer.js' is not defined`。
- 原因：打印预览页和打印机管理页静态依赖打印运行模块，真机包中该模块缺失或开发者工具缓存旧包时，会导致 require 队列报错，并连带影响其他页面显示。
- 修复：打印预览页、打印机管理页改为按需加载打印运行模块，并增加缺失兜底提示。
- 结果：首页、我的、检测记录、开证等核心页面不再被打印模块拖垮；打印模块未加载时只提示“打印模块未加载，请重新构建小程序”，不再白屏。

### 1. 我的页面

- 恢复正常中文和完整模板。
- 进入页面后刷新企业信息。
- 展示企业名称、联系人、联系电话、企业地址、服务期限、服务状态。
- 增加修改密码提示、清除账号、退出登录。
- 增加 loading、错误和空状态，避免白屏。

### 2. 开具合格证流程

- 开证页改为稳定单页流程。
- 从检测详情或旧表单入口进入时，先保存检测记录 ID，再进入开证页。
- 开证页按检测记录 ID 调用检测详情接口。
- 自动带入产品名称、检测时间、检测项目、检测结论。
- 自行检测合格必须选择合格检测记录。
- 质量安全控制、委托检测支持上传图片/PDF 依据资料。
- 提交成功后进入生成成功页。

### 3. 检测记录与选择检测记录

- 检测记录列表恢复正常中文。
- 检测详情增加 loading、错误、空状态。
- “开具合格证”按钮改为通过本地状态传递 record_id，避免 tabBar query 丢失。
- 选择检测记录页只展示可用于开证的合格记录。

### 4. 合格证与打印预览

- 合格证列表、详情、生成成功页恢复正常中文。
- 合格证详情保留复制扫码链接、打印、作废功能。
- 打印预览页恢复正常中文，展示 K329 连接状态和 60×80mm 标签预览。
- 打印失败提示中文化，不显示底层技术字段。

### 5. 空状态和错误状态

- 首页、检测记录、检测详情、选择检测记录、开证页、合格证列表、合格证详情、打印预览、我的页面均补充基础 loading/空状态/错误状态。
- 网络异常统一提示“网络异常，请稍后重试”。
- 登录失效统一回到登录页。
