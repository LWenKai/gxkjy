# 第21步 全端视觉与布局升级记录

## 升级目标

本次仅做后台管理端、小程序端、扫码公开页的视觉与布局升级，不新增复杂业务功能，不接真实检测仪器，不接真实打印机，不发布微信小程序。

## 统一设计方向

- 主色调整为更有科技感的深绿、青绿、青蓝组合。
- 页面背景使用浅灰绿和轻量科技渐变，避免临时工程页观感。
- 卡片、按钮、状态标签、搜索区、表格、手机预览框统一圆角、阴影和间距。
- 状态表达保留业务清晰度：合格/正常/有效用绿色，不合格/作废/异常用红橙色。

## 后台管理端升级内容

- 优化后台全局主题、侧边栏、顶部栏、卡片、表格、搜索区、统计卡片。
- Dashboard 增加科技感欢迎区，数据卡片更清晰，点击属性保持不变。
- 小程序预览页手机外框、流程导航、预览卡片和按钮风格同步升级。
- 登录页、通用面板和表格交互视觉更接近正式 SaaS 管理系统。

## 小程序端升级内容

- 优化全局背景、卡片、按钮、标签、输入框、返回按钮。
- 登录页增加更正式的品牌区域和客户登录卡片。
- 首页升级为客户工作台风格，统计卡和核心入口更突出。
- 开具合格证页优化承诺依据卡片、已选检测记录、依据资料和承诺事项展示。
- 合格证详情、打印机连接、打印预览页面视觉更接近正式凭证和标签。

## 扫码公开页升级内容

- 顶部改为可信扫码查询视觉区。
- 正常、作废、无效状态保持清晰区分。
- 合格证编号独立高亮展示。
- 证书信息、检测结果、企业公开资料、可信说明卡片化展示。
- 继续隐藏设备编号、厂家编码、账号、密钥、内部 token 等技术字段。

## 不影响的业务逻辑

- 后台登录、企业管理、设备管理、检测记录、合格证管理逻辑不变。
- 小程序 demo 登录、开证流程、承诺依据、依据资料上传、模拟打印、作废逻辑不变。
- 扫码公开页查询接口和公开展示规则不变。
- 本次没有新增数据库 migration。

## 部署说明

本次修改涉及 `admin-web`、`miniapp`、`public-h5` 和文档。`backend` 业务代码未修改，如线上部署只需重建 `admin-web` 与 `public-h5`；`miniapp` 只构建，不发布。

## 暂未处理

- 未接入真实打印机。
- 未接入真实检测仪器。
- 未发布微信小程序体验版或正式版。

## 下一步建议

完成线上视觉验证后，可进入小程序备案通过后的体验版上传准备与真实手机体验测试。
