# 官网资料管理后台使用说明

## 入口

登录管理后台：

`https://admin.gxkjy.com/`

左侧菜单进入：

官网 -> 官网资料

## 上传资料

点击“上传资料”，填写：

1. 资料名称
2. 资料分类
3. 简介
4. 排序
5. 是否公开
6. 是否推荐首页

选择文件后上传。

## 支持格式

支持：

1. jpg / jpeg / png / webp
2. pdf
3. doc / docx
4. xls / xlsx
5. ppt / pptx

单文件最大 20MB。

## 公开规则

1. 设置为“公开”的资料会展示在官网资料中心。
2. 设置为“隐藏”的资料只在后台可见。
3. 设置“推荐首页”的资料会优先展示在官网推荐资料区域。
4. 删除资料后，官网不再展示。

## 注意事项

不要上传包含密码、密钥、客户隐私、合同敏感条款的文件。

官网资料仅用于客户了解谷芯科技业务，不等同于监管正式报表。
