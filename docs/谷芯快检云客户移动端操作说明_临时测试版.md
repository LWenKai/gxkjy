# 谷芯快检云客户移动端操作说明_临时测试版

> 本说明面向企业客户工作人员。当前为临时测试环境，打印功能为模拟打印，真实蓝牙打印后续接入。

## 1. 客户登录

做什么：

- 登录客户移动端，查看本企业检测记录和合格证。

怎么做：

1. 打开客户移动端。
2. 输入账号和密码。
3. 点击“登录”。

演示账号：

- 账号：`demo`
- 密码：`Demo@2026`

注意：

- 企业服务到期后不能登录。
- 企业或账号被停用后不能登录。
- 忘记密码时，请联系后台管理员重置。

## 2. 查看首页

做什么：

- 快速查看企业当前检测和开证情况。

首页会显示：

- 企业名称。
- 服务状态和到期提醒。
- 今日检测数量。
- 可开证记录数量。
- 今日开证数量。
- 最近检测记录。
- 最近合格证。

注意：

- 首页只展示常用入口，避免操作复杂。
- 当前显示“模拟打印，真实打印待接入”。

## 3. 查看检测记录

做什么：

- 查看本企业所有检测记录。

怎么做：

1. 点击底部“检测记录”。
2. 可选择“全部、合格、不合格”。
3. 可输入产品或样品名称搜索。
4. 点击一条记录进入详情。

注意：

- 客户只能查看自己企业的数据。
- 客户不能修改检测记录。
- 客户不能删除检测记录。

## 4. 查看检测记录详情

详情中可以看到：

- 产品名称。
- 样品名称。
- 检测时间。
- 检测结论。
- 检测项目明细。
- 检测值、单位、限量值和判定结果。

如果记录合格且状态正常，会显示“开具合格证”按钮。

如果记录不合格、被作废、被隐藏或被标记异常，会显示不可开证提示。

## 5. 开具合格证

做什么：

- 为合格检测记录开具合格证。

怎么做：

1. 点击“开具合格证”。
2. 选择一条可开证记录。
3. 系统会自动带出产品名称、企业信息、联系电话等内容。
4. 填写数量、单位、产地、开证人等信息。
5. 选择合格证类型：
   - 农产品质量安全承诺达标合格证
   - 企业快检合格标签
6. 点击提交。
7. 成功后进入合格证详情。

注意：

- 不合格记录不能开证。
- 合格证编号由系统自动生成，客户不需要填写。
- 当前不支持自动开证，需要人工确认后提交。

## 6. 查看已开合格证

做什么：

- 查看本企业已经开具过的合格证。

怎么做：

1. 点击底部“已开证”。
2. 可选择“全部、正常、已作废”。
3. 可输入产品名称或合格证编号搜索。
4. 点击一张合格证查看详情。

列表会显示：

- 合格证编号。
- 产品名称。
- 数量和单位。
- 开证日期。
- 当前状态。

## 7. 查看合格证详情

详情中可以看到：

- 合格证编号。
- 合格证类型。
- 产品名称。
- 数量和单位。
- 产地。
- 开证主体。
- 联系电话。
- 开具时间。
- 对应检测记录和检测项目明细。
- 扫码查看链接。

注意：

- 页面不显示内部技术字段。
- 已作废合格证不能打印。

## 8. 复制扫码链接

做什么：

- 把合格证公开链接发给客户、采购方或现场人员查看。

怎么做：

1. 进入合格证详情。
2. 点击“复制扫码链接”。
3. 系统提示复制成功后，可粘贴发送。

注意：

- 正常合格证打开后显示“查询有效”。
- 作废合格证打开后会明显提示“合格证已作废”。

## 9. 模拟打印

做什么：

- 在真实打印机接入前，验证标签内容和打印流程。

怎么做：

1. 进入正常合格证详情。
2. 点击“标签预览”。
3. 查看 60×80mm 标签预览。
4. 点击“模拟打印”。
5. 系统提示“模拟打印记录已保存”。

注意：

- 当前不连接真实打印机。
- 当前不调用蓝牙。
- 当前不接优博讯 K329 SDK。
- 真实打印后续会通过打印适配层接入。

## 10. 作废合格证

做什么：

- 当合格证开错或不再使用时，将其作废。

怎么做：

1. 进入合格证详情。
2. 点击“作废合格证”。
3. 系统会要求二次确认。
4. 确认后，合格证状态变为“已作废”。

注意：

- 作废后不能打印。
- 作废后公开页会显示“合格证已作废”。
- 原检测记录仍可重新开具新的合格证。

## 11. 查看企业信息

做什么：

- 查看当前登录企业和服务状态。

怎么做：

1. 点击底部“我的”。
2. 查看企业名称、联系人、联系电话、服务有效期、当前账号。

注意：

- 客户端暂不支持修改企业资料。
- 企业资料由后台管理员维护。

## 12. 退出登录

做什么：

- 当前设备不再使用时退出账号。

怎么做：

1. 进入“我的”。
2. 点击“退出登录”。
3. 下次使用时重新输入账号密码。

## 13. 常见问题说明

### 为什么看不到检测记录？

- 当前企业还没有检测记录。
- 搜索条件过窄。
- 检测数据还未由后台测试录入或仪器上传。

### 为什么合格证开不了？

- 检测结果不合格。
- 检测记录被后台隐藏、作废或标记异常。
- 该记录不属于当前企业。

### 为什么不能真实打印？

- 当前是测试阶段，只支持模拟打印。
- 真实打印需要等打印机资料确认后接入。

### 为什么登录失败？

- 账号或密码错误。
- 企业服务到期。
- 企业或账号被停用。
- 请联系后台管理员处理。
