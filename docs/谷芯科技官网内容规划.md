# 谷芯科技官网内容规划

## 官网定位

谷芯科技官网用于展示山西谷芯科技有限公司在食品安全快检场景中的产品配套与服务能力。对外统一使用“谷芯科技”，不突出供应商品牌，不写“自主研发平台”，不写无法证明的资质或案例。

## 页面结构

1. 首页
2. 解决方案
3. 产品与服务
4. 谷芯快检云
5. 快检室建设
6. 资料中心
7. 关于我们
8. 联系我们

## 核心文案口径

可以表达：

1. 食品安全快检一站式设备供应与配套服务。
2. 提供快检室建设、检测设备、试剂耗材、合格证打印、数据平台等配套。
3. 可根据客户场景提供基础型、标准型、提升型配置建议。
4. 山西省内可根据项目情况提供上门服务，省外可远程指导或协商服务方式。
5. 谷芯快检云提供检测记录、合格证开具、扫码查询和打印管理能力。

避免表达：

1. 自主研发平台。
2. 专业技术团队。
3. 国家指定、官方监管平台。
4. 包过验收、确保、永久、终身。
5. 无法证明的厂家授权和项目案例。

## 重点场景

1. 农产品合作社快检室。
2. 食材配送企业快检室。
3. 学校食堂快检室。
4. 食品加工企业快检室。
5. 农贸市场 / 市集快检室。
6. 监管或第三方配套场景。
