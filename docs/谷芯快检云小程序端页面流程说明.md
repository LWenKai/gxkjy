# 谷芯快检云小程序端页面流程说明

## 页面结构

小程序底部入口包括：

1. 首页
2. 检测记录
3. 开具合格证
4. 开证记录
5. 我的

二级页面包括：

1. 检测详情
2. 选择检测记录
3. 合格证详情
4. 打印预览
5. 打印机连接

所有二级页面均提供返回入口；如果没有上一页，则返回首页或对应主页面。

## 首页

首页展示企业名称、服务状态、今日检测数、可开证记录数、今日开证数、已开证总数、打印机状态、最近检测记录和最近合格证。

统计卡片和快捷入口可跳转到对应页面。

## 开具合格证

开证流程为：

1. 选择承诺依据。
2. 根据承诺依据选择检测记录或上传依据资料。
3. 填写产品名称、产品数量/重量、单位、产地、承诺主体、联系方式、打印份数等信息。
4. 确认承诺事项。
5. 生成合格证。

生成成功后进入合格证详情，可复制扫码链接、打印合格证或返回首页。

## 开证记录

开证记录支持按状态和时间筛选，点击记录进入合格证详情。详情页展示证书信息、产品信息、承诺信息、依据材料、扫码链接和打印记录。

## 打印

当前为模拟打印。打印预览页展示 60×80mm 标签结构化内容，点击模拟打印会记录打印日志。
