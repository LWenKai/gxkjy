# 客户经营模块第二阶段：销售产品库、报价附件与采购单升级记录

## 本次目标

本阶段在不影响企业端、小程序端、检测记录、合格证和扫码公开页的前提下，完善谷芯内部销售管理能力：

1. 报价记录支持上传和管理报价附件。
2. 新增独立的内部销售产品库。
3. 将原单产品采购记录升级为采购单主表 + 多项产品明细。
4. 复购提醒改为按采购明细产品独立提醒。

## 重要边界

后台原有“产品库”继续服务企业常用农产品、小程序开证和客户交付，不参与本次内部销售产品管理。

本次新增入口为：

销售管理 → 销售产品库

该模块只供谷芯内部超级管理员使用，不开放给客户企业端、小程序端或公开扫码页。

## 数据库变化

新增模型：

1. `sales_products`：内部销售产品库。
2. `customer_quote_attachments`：报价附件。
3. `customer_purchase_orders`：采购单主表。
4. `customer_purchase_items`：采购明细与复购提醒。

新增枚举：

1. `SalesProductCategory`
2. `PurchasePaymentStatus`
3. `PurchaseDeliveryStatus`
4. `RepurchaseStatus`

迁移文件：

`backend/prisma/migrations/20260715193000_sales_products_purchase_orders/migration.sql`

## 旧采购数据迁移

旧表 `customer_purchases` 保留不删除。

迁移规则：

1. 每条旧采购记录迁移为一张采购单。
2. 每张迁移采购单包含一条采购明细。
3. 旧产品名称保存为产品快照。
4. 旧金额迁移为订单总额和明细小计。
5. 数量合法时用金额除以数量计算单价；数量为空或异常时按 1 处理。
6. 迁移备注会追加“由旧采购记录迁移”。

## 后台页面说明

### 销售产品库

支持新增、编辑、搜索、分类筛选、启停、软删除和图片上传。

适合录入：

1. 检测仪器；
2. 农残酶试剂；
3. 胶体金检测卡；
4. 实验耗材；
5. 打印设备；
6. 标签纸；
7. 数据终端；
8. 软件平台；
9. 安装培训维修服务。

### 客户详情

报价记录增加附件区域，可上传 PDF、Excel、Word、图片。

采购与复购区域展示采购单。展开采购单可查看多项产品明细、单价、小计、补货日期和复购状态。

### 数据看板

“近期需要跟进客户”改为读取采购明细中的复购提醒，支持一张采购单内多个产品独立提醒。

## 上传限制

报价附件允许：

`.pdf`、`.xls`、`.xlsx`、`.doc`、`.docx`、`.jpg`、`.jpeg`、`.png`

单文件最大 20MB。

销售产品图片允许：

`.jpg`、`.jpeg`、`.png`

单文件最大 5MB。

后端同时校验扩展名、MIME 类型、文件大小和存储路径。

## 不影响内容

本次没有修改：

1. 企业端产品库用途；
2. 小程序开证流程；
3. 检测记录上传；
4. 合格证开具；
5. 扫码公开页；
6. 设备绑定流程；
7. 厂家数据接口。
