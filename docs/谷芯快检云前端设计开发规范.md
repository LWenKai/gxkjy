# 谷芯快检云前端设计开发规范

## 一、设计目标

谷芯快检云前端统一追求：清爽、正式、可信、现代、有科技感，适合食品安全快检 SaaS 系统。页面应便于管理人员长期使用，也要适合客户和消费者扫码查看。

## 二、颜色规范

1. 主色：`#0f7a32`，用于主按钮、重点状态、品牌标题。
2. 主色深色：`#086226`，用于按钮 hover、强调文字。
3. 主色浅底：`#e8f5ec`，用于选中菜单、成功标签背景。
4. 辅助蓝：`#266ca8`，用于环境标识、提示型信息。
5. 页面背景：`#f5f8f6`，保持干净浅灰绿。
6. 卡片背景：`#ffffff` 或接近白色的半透明白。
7. 边框：`#dfe8e2`，浅而清楚。
8. 正文：`#1f2d24`。
9. 辅助文字：`#66756c`。
10. 成功状态：绿色系。
11. 警告状态：`#d27a00`。
12. 危险状态：`#c7352d`。

## 三、字号规范

1. 页面标题：24-28px。
2. 卡片标题：18-20px。
3. 表格表头：14px，加粗。
4. 正文：14px。
5. 辅助说明：12-13px。
6. 移动端扫码页主状态标题：24-28px。

不得使用随视口宽度变化的字体大小。

## 四、布局规范

1. 后台主体内边距：桌面端 24-32px，窄屏 16-18px。
2. 卡片圆角：8-12px，避免过度圆角。
3. 卡片阴影：轻阴影，不做大屏风格强发光。
4. 页面之间统一使用卡片分区，不要在卡片中嵌套卡片。
5. 详情页按业务分区展示：基础信息、关联信息、明细信息、操作信息。
6. 表单最大宽度不宜过宽，常规表单控制在 920px 内。

## 五、搜索区规范

1. 搜索区使用浅色卡片承载。
2. 表单项横向排列，窄屏自动换行。
3. 搜索、重置、导出按钮放在同一行末尾或自然换行。
4. 不允许固定死宽度导致页面溢出。
5. 输入框宽度建议 220-260px。

## 六、表格规范

1. 表格行高保持舒适，单元格上下内边距约 12px。
2. 重要字段优先展示，不重要字段放详情。
3. 长文本使用省略号，并提供 tooltip 或详情查看。
4. 操作列宽度预留足够空间，按钮允许换行但不能挤压主字段。
5. 表格横向滚动仅用于字段较多的管理表格，不能让整页横向溢出。
6. 状态列统一使用标签展示。

## 七、按钮规范

1. 主要动作使用绿色主按钮。
2. 危险动作使用红色或文字按钮，并必须二次确认。
3. 表格内操作按钮使用文字按钮，按钮之间保持 8px 左右间距。
4. 不做删除企业、删除检测记录、删除合格证等破坏性业务按钮。

## 八、状态标签规范

1. 正常、公开、合格：绿色。
2. 停用、隐藏：灰色。
3. 即将到期、待处理：橙色。
4. 作废、不合格、异常：红色。
5. 标签文案必须是中文业务词，不显示数据库枚举给用户。

## 九、空状态和加载状态

1. 空状态必须使用中文说明，例如“暂无检测记录”“暂无公开资料”。
2. 加载状态使用统一 loading，不显示调试信息。
3. 接口失败提示必须可理解，例如“加载失败，请稍后重试”。

## 十、响应式规则

1. 页面主体不能固定死宽度导致溢出。
2. 搜索区在窄屏时自动换行。
3. 表格操作按钮不能挤压主要字段。
4. 长文本要省略并提供 tooltip。
5. 表格列宽要合理，必要时只让表格内部滚动。
6. 详情页卡片在窄屏下单列展示。
7. 表单字段在窄屏下自动堆叠。
8. 不允许出现明显横向滚动，除非是表格必要滚动。

## 十一、扫码公开页规则

1. 移动端优先，适配 360px 到 430px 宽度。
2. 顶部必须突出“谷芯快检云合格证查询”。
3. 正常状态显示“查询有效”。
4. 作废状态显示“合格证已作废”，颜色明显区分。
5. 无效链接显示“未查询到对应合格证信息”，不展示假数据。
6. 重点展示状态、合格证编号、产品名称、检测结论和检测项目明细。
7. 企业资料只展示后台设置为公开的内容。
8. 不显示设备编号、厂家编码、账号、密钥、后台内部字段。
9. 底部必须展示技术支持和风险说明，不能夸大为监管平台或第三方检测报告。

## 十二、后续开发要求

1. 新页面应优先复用现有全局样式类。
2. 页面上线前必须检查窄屏、自适应、表格列宽和按钮换行。
3. 上传、删除、作废等动作必须有明确反馈和必要确认。
4. 任何涉及密钥、密码、token 的字段不得在前端展示。
