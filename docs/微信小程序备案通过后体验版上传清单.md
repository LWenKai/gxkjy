# 微信小程序备案通过后体验版上传清单

## 当前状态

1. 微信认证已通过。
2. 小程序备案资料已提交，正在等待审核。
3. 备案通过前不要正式发布小程序。
4. 当前系统仍是正式测试环境，真实检测仪器和真实打印机尚未接入。

## 备案通过前可以准备

1. 准备小程序 AppID，填入微信开发者工具项目配置。
2. 检查小程序接口地址是否为：`https://api.gxkjy.com/api`。
3. 检查代码中不要残留临时 IP、localhost、调试 token、密码等敏感输出。
4. 本地执行小程序构建，确认 `miniapp/dist/build/mp-weixin` 可以生成。
5. 准备体验版测试账号：`demo / Demo@2026`。

## 备案通过后先做体验版

1. 在微信公众平台配置 request 合法域名：`https://api.gxkjy.com`。
2. 如后续小程序内打开扫码页，再配置 web-view 业务域名：`https://cert.gxkjy.com`。
3. 使用微信开发者工具导入目录：`miniapp/dist/build/mp-weixin`。
4. 填写自己的小程序 AppID。
5. 上传体验版。
6. 添加体验成员。
7. 用体验版测试账号登录：`demo / Demo@2026`。
8. 验证检测记录、开具合格证、合格证详情、模拟打印等主流程。
9. 当前真实检测仪器未接入，检测数据仍以后台测试数据为主。
10. 当前真实打印机未接入，打印仍为模拟打印，仅用于演示验证。

## 暂不做

1. 不上传正式版。
2. 不提交正式审核。
3. 不接入真实蓝牙打印。
4. 不接入优博讯 K329 SDK。
5. 不接入真实检测仪器厂家接口。

## 提醒

体验版测试通过后，再根据页面、文案、备案状态和客户反馈决定是否进入正式提审。
