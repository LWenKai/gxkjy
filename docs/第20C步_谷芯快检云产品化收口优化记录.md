# 第20C步 谷芯快检云产品化收口优化记录

## 一、优化目标

本次围绕真实客户交付场景做收口优化，不新增官网，不接真实检测仪，不接真实打印机，不调用蓝牙，不发布微信小程序。

重点目标：

1. 让客户开具合格证更简单；
2. 让谷芯内部测试、演示、联调更清楚；
3. 让设备绑定和换绑更安全；
4. 让扫码公开页更正式、更可信；
5. 保持现有后台、小程序、扫码页核心业务不被破坏。

## 二、主要修改内容

### 1. 小程序开具合格证页面

已将原先“1 选择依据 / 2 填写信息 / 3 生成证书”的步骤条式页面，调整为一个完整开证页：

1. 选择承诺依据；
2. 选择检测记录或上传依据资料；
3. 填写产品信息；
4. 填写承诺信息；
5. 填写开证信息；
6. 点击“生成合格证”。

保留能力：

1. 自行检测合格必须选择合格检测记录；
2. 质量安全控制符合要求、委托检测合格支持上传图片/PDF 依据资料；
3. 产品名称、产地、承诺主体、联系电话按企业信息默认带入；
4. 支持复制上一张合格证信息；
5. 支持保存常用产品；
6. 不显示 API、token、public_token 等技术字段。

### 2. 后台测试检测数据页面

已改为“测试中心”，用于内部测试、客户演示和厂家联调。

页面提供：

1. 选择企业；
2. 选择设备；
3. 生成测试合格数据；
4. 生成测试异常数据；
5. 生成演示数据。

说明：当前仍基于已有测试检测记录接口生成测试数据，不接真实检测仪，不代表真实检测结果。

### 3. 设备管理页面

已重新整理设备管理页面：

1. 表格操作区改为“更多操作”，避免按钮换行、拥挤；
2. 保留查看详情、编辑设备、绑定/换绑企业、解绑设备、启停设备；
3. 新增/编辑设备时厂家编码来自厂家接口选择，不让用户手填；
4. 换绑设备时展示设备编号、厂家、当前企业、目标企业；
5. 换绑前二次确认，并提示后续检测数据归属变化；
6. 导出增加确认弹窗。

### 4. 扫码公开页

已重写扫码公开页展示结构：

1. 正常、作废、无效三种状态区分更明显；
2. 顶部展示“谷芯快检云 / 食品安全追溯查询”；
3. 合格证编号、查询时间、开具时间、承诺主体、联系方式等信息分组展示；
4. 检测项目改为卡片化展示；
5. 公开依据资料、企业公开资料分区展示；
6. 增加可信查询说明；
7. 不展示设备编号、厂家编号、账号、密钥、token 等敏感字段。

### 5. 通用文字修复

修复了小程序格式化工具和页面配置中的乱码文案，确保新开证页、底部导航、常用状态文案显示为正常中文。
