# 谷芯快检云后台数据导出说明

## 支持导出的模块

后台当前支持以下模块导出 CSV：

- 企业管理
- 设备管理
- 检测记录
- 合格证管理
- 产品库
- 操作日志

## 使用方式

1. 进入对应后台页面。
2. 根据需要设置查询条件，例如企业、状态、日期等。
3. 点击搜索区右侧的“导出”按钮。
4. 浏览器会下载 CSV 文件。

导出内容会按当前筛选条件生成，不会因为当前分页只显示 10 条而只导出 10 条。

## 文件格式

- 文件格式：CSV
- 编码：UTF-8 BOM
- 文件名：中文模块名 + 日期

如果 Windows Excel 打开仍出现中文乱码，可以先打开 Excel，再通过“数据 - 从文本/CSV”导入，编码选择 UTF-8。

## 不导出的敏感字段

导出文件不会包含：

- 管理员密码
- 客户账号密码
- `password_hash`
- JWT 或登录 token
- OSS 密钥
- 数据库密码
- 厂家接入密钥 `access_secret`
- 内部 public token 字段名
- 不适合公开的内部请求签名字段

## 适用场景

导出数据适合用于：

- 客户演示
- 售后排查
- 数据核对
- 阶段性留档
- 内部运营统计

## 注意事项

导出数据不等于监管正式报表，也不等同第三方检测报告。第一版导出能力只用于平台内部管理和客户服务辅助。
