# 第22A步 打印机与检测仪对接前置资料记录

## 一、本次范围

本次只做真实设备对接前的工程和资料准备：

1. 打印机对接前置结构；
2. 打印机厂家资料确认清单；
3. 真实打印机对接技术方案草案；
4. 检测仪厂家版对接说明；
5. 检测仪厂家资料确认清单；
6. 检测仪内部联调手册；
7. 检测仪上传字段说明和 curl 示例。

本次没有真实接入打印机，没有调用蓝牙，没有接入优博讯 SDK，没有真实接入检测仪。

## 二、打印机前置工程

已补齐 `packages/print-core` 的基础结构：

1. `PrinterAdapter`；
2. `MockPrinterAdapter`；
3. `CertificatePrintPayload`；
4. `CertificateLabelTemplate`；
5. `createPrintJob`；
6. `buildCertificateLabel`。

该结构用于明天判断走厂家 SDK、蓝牙指令、图片打印或 Android 终端方案。

## 三、检测仪接口审计

当前 Prisma schema 已具备以下基础表：

1. 厂家接口；
2. 设备；
3. 检测记录；
4. 检测项目；
5. 厂家上传日志。

当前源码未发现正式开放的 `/api/open/detection/upload` 控制器。本次未新增该公网接口，避免在厂家资料未确认前上线半成品。

## 四、上传日志能力

数据库已存在 `manufacturer_upload_logs` 表，可用于后续记录厂家上传请求和错误原因。后台日志查看页面后续需要补齐。
