# 小程序端人工测试清单（重构版）

## 登录

- 使用 demo / Demo@2026 登录。
- 登录失败时提示清楚。
- 登录后进入首页。

## 首页

- 企业名称显示正确。
- 今日检测、可开证、今日开证、已开证总数显示。
- 统计卡片和快捷入口可跳转。
- 打印机状态显示为模拟打印。

## 检测记录

- 检测记录列表可加载。
- 支持全部、合格、不合格筛选。
- 检测详情显示项目明细。
- 不合格、异常、隐藏、作废记录显示不可开证原因。

## 开具合格证

- 默认承诺依据为自行检测合格。
- 自行检测合格必须选择合格检测记录。
- 质量安全控制符合要求必须上传资料。
- 委托检测合格必须上传资料。
- 产品数量/重量和打印份数区分清楚。
- 生成成功后进入合格证详情。

## 开证记录

- 列表显示合格证编号、产品、数量、状态、承诺依据。
- 详情显示证书信息、承诺信息、依据材料、扫码链接。
- 可复制扫码链接。
- 可作废合格证。

## 打印

- 打印预览页显示 60×80mm 标签信息。
- 模拟打印能写入日志。
- 已作废合格证不可打印。

## 扫码公开页

- 正常证书显示查询有效。
- 作废证书显示已作废。
- 无效链接显示未查询到信息。
- 不展示设备编号、厂家编码、客户账号、密钥。
