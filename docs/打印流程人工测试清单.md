# 打印流程人工测试清单

本文用于测试谷芯快检云打印流程。当前阶段仍为模拟打印，真实打印机接入后可继续沿用此清单扩展。

## 一、模拟打印测试

| 序号 | 测试项 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 1 | 客户登录小程序 | 登录成功，进入首页 |  |
| 2 | 进入开证记录 | 能看到已开合格证 |  |
| 3 | 打开正常合格证详情 | 显示合格证信息、扫码链接、打印入口 |  |
| 4 | 点击打印合格证 | 进入打印预览页 |  |
| 5 | 查看 60×80mm 标签预览 | 产品、数量、产地、主体、电话、日期、编号、二维码信息完整 |  |
| 6 | 点击模拟打印 | 提示模拟打印记录已保存 |  |
| 7 | 返回合格证详情 | 打印记录中出现模拟打印记录 |  |
| 8 | 打开打印机连接页 | 显示当前为模拟打印，真实打印待接入 |  |
| 9 | 点击连接打印机 | 弹窗说明真实打印待接入，不调用蓝牙 |  |
| 10 | 作废合格证后再打印 | 打印按钮不可用或提示不可打印 |  |

| 序号 | 测试项 | 预期结果 | 结果 |

| 3 | 断开后重连 | 可重新连接 |  |

## 三、注意事项

1. 当前不要在小程序里申请蓝牙权限；
2. 当前不要连接真实打印机；
3. 当前不要上传体验版；
4. 真实打印接入前，所有打印均视为模拟流程验证。
