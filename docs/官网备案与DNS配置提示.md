## ICP 备案提醒

服务器位于中国内地时，网站正式对外访问通常需要完成 ICP 备案。备案未完成时，域名访问可能被拦截或无法正常打开。

## HTTPS 证书

DNS 生效后再申请证书。

建议证书包含：

1. `www.gxkjy.com`
2. `gxkjy.com`

证书完成后再配置：

1. HTTP 自动跳转 HTTPS。
2. `gxkjy.com` 跳转到 `www.gxkjy.com`。
