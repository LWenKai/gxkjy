# 第19B步 企业详情新增设备默认绑定与后台收口记录

## 本次收到的人工反馈

1. 在企业详情页新增设备后，设备应默认绑定到当前企业。
2. 设备新增、绑定、列表刷新和错误提示需要更贴近真实使用。
3. 企业详情页需要更适合开户后的连续操作：复制客户使用信息、查看业务概览、快速进入检测记录和合格证。
4. 合格证详情复制扫码链接、检测记录不可开证原因、页面对齐和按钮拥挤问题需要继续收口。
5. 微信认证已通过，小程序备案仍在审核，需要准备体验版上传检查材料，但本阶段不发布小程序。

## 企业详情新增设备未自动绑定的原因

审计后确认，后端设备创建接口 `POST /api/admin/devices` 已支持传入 `company_id`，创建时可直接绑定企业。

问题主要在前端企业详情页：

1. 企业详情页原先只展示已绑定设备列表；
2. 页面只有“查看设备管理”入口，没有“新增并绑定设备”入口；
3. 因此从企业详情页无法带着当前企业上下文创建设备；
4. 设备创建成功后也没有对应的企业详情设备列表刷新流程。

本次采用前端串联现有接口的轻量修复方案：在企业详情页新增专用弹窗，调用现有创建设备接口并传入当前企业 ID。

## 修复方案

1. 从设备管理页新增设备：保持原逻辑，可新增到设备池，后续手动绑定企业。
2. 从企业详情页新增设备：新增“新增并绑定设备”弹窗，当前企业名称只读展示。
3. 厂家编码由所选厂家接口带出，不再手填。
4. 设备名称、设备编号为必填。
5. 提交时调用现有创建设备接口并传入 `company_id`。
6. 创建成功后提示“设备已新增并绑定到当前企业”。
7. 创建成功后刷新企业详情设备列表和企业业务概览。

## 本次新增或修改内容

1. 新增后端接口：`GET /api/admin/companies/:id/summary`。
2. 企业详情页新增业务概览卡片：
   - 绑定设备数；
   - 检测记录数；
   - 合格证总数；
   - 正常合格证数；
   - 作废合格证数。
3. 企业详情页新增“复制客户使用信息”按钮。
4. 企业详情页设备区域改为“绑定设备”，新增按钮改为“新增并绑定设备”。
5. 检测记录页面增加不可开证原因提示。
6. 合格证详情公开链接操作文案优化为“复制扫码链接”“打开扫码页”。
7. 新增企业后弹出下一步建议，可直接进入企业详情继续创建账号和绑定设备。
