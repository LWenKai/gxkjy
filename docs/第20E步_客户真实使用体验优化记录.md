# 第20E步：客户真实使用体验优化记录

## 一、优化目标

本次围绕客户第一次使用小程序的核心闭环进行收口：

登录 → 首页 → 检测记录 → 开具合格证 → 合格证详情 → 打印预览 → 我的。

重点是减少客户填写内容、避免白屏、避免技术字段暴露，并修复真机打印页面因 `print/printer.js` 缺失导致的空白问题。

## 二、修复和优化内容

### 1. 小程序首页

- 首页改为客户工作台结构。
- 突出显示：
  - 今日检测；
  - 可开证；
  - 今日开证。
- 主要入口保留：
  - 开具合格证；
  - 检测记录；
  - 合格证记录。
- 最近检测、最近合格证保留为辅助信息。
- 增加加载、空状态、错误状态提示，避免白屏。

### 2. 开具合格证页面

- 去掉复杂步骤感，改成单页填写。
- 默认承诺依据为“自行检测合格”。
- 选择检测记录后自动带入：
  - 产品名称；
  - 检测时间；
  - 检测项目；
  - 检测结论。
- 客户主要填写：
  - 产品数量；
  - 单位；
  - 产地；
  - 承诺主体；
  - 联系电话；
  - 打印份数。
- 支持常用产品选择和保存。
- 质量控制、委托检测仍支持图片/PDF 依据资料上传。
- 所有错误提示改为中文业务提示。

### 3. 合格证详情页

- 顶部突出：
  - 产品名称；
  - 合格证状态；
  - 合格证编号。
- 主要按钮调整为：
  - 查看二维码；
  - 打印合格证；
  - 返回首页。
- 检测项目、依据资料、二维码链接、打印记录分区展示。
- 不展示 `public_token`、JWT、接口地址等技术字段。

### 4. 打印预览页

- 打印页不再展示“模拟打印”文案。
- 未连接打印设备时提示：
  - 请先连接打印设备。
- 点击打印时，如果未连接打印机，自动引导到打印机管理页。
- 标签预览继续按 60×80mm 合格证标签展示。
- 修复真机报错：
  - `module 'print/printer.js' is not defined`
- 调整为静态打包打印模块，构建产物中已生成：
  - `miniapp/dist/build/mp-weixin/print/printer.js`

### 5. 我的页面

- 增加客户常用入口：
  - 企业资料；
  - 常用产品；
  - 打印机管理；
  - 使用帮助；
  - 联系客服。
- 客服电话：
  - 13363412262
- 保留：
  - 修改密码说明；
  - 清除账号；
  - 退出登录。
- 企业信息接口异常时显示中文提示，不再白屏。

### 6. 使用帮助

- 新增客户可读的使用帮助内容：
  - 如何查看检测记录；
  - 如何开具合格证；
  - 如何打印合格证；
  - 不合格记录怎么办；
  - 服务到期怎么办；
  - 联系谷芯科技。

### 7. 后台企业使用概览

- 后台企业详情中已有并保留：
  - 最近登录时间；
  - 最近检测时间；
  - 最近开证时间。
- 本轮未新增后端字段，避免不必要的数据库改动。
