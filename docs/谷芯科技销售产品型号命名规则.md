# 谷芯科技销售产品型号命名规则

## 一、总体原则

销售产品库中的“型号”用于谷芯内部报价、套餐、成交订单和售后识别。第一版只记录谷芯内部销售型号，不再区分“销售型号”和“厂家型号”。

页面中的“厂家”只用于记录真实供货厂家或设备厂家；如果产品对外统一按谷芯服务销售，可不填写厂家。

## 二、检测仪型号规则

检测仪型号沿用《食品安全检测仪的命名规则》：

`GX-核心功能代码 + 技术类型代码 + 通道数量 + 配置级别 + 产品形态`

核心功能代码：

- `N`：农药残留检测
- `S`：兽药残留检测
- `Z`：综合多功能检测

技术类型代码：

- `E`：酶抑制或酶联免疫类
- `G`：胶体金免疫层析类
- `P`：光谱分析类

配置级别：

- `L`：基础型
- `M`：标准型
- `H`：提升型

产品形态：

- `H`：手持
- `P`：便携
- `S`：标准台式

示例：

- `GX-ZP20MS`：谷芯综合多功能光谱类 20 通道标准型台式检测仪
- `GX-NE12MS`：谷芯农残酶法 12 通道标准型台式检测仪
- `GX-ZGXMS`：谷芯综合胶体金读卡标准型设备

## 三、试剂和检测卡型号规则

试剂：

`GX-RE-检测方向 + 规格`

- `GX-RE-NC500`：农残检测酶试剂，500 规格

检测卡：

`GX-CG-检测项目`

- `GX-CG-SR3`：瘦肉精三联检测卡
- `GX-CG-AFB1`：黄曲霉毒素 B1 检测卡
- `GX-CG-MG`：孔雀石绿检测卡
- `GX-CG-CAP`：氯霉素检测卡

## 四、耗材型号规则

实验室及取样耗材：

`GX-LC-耗材代码`

- `GX-LC-CUP`：样品杯
- `GX-LC-TIP`：移液枪枪头
- `GX-LC-TUBE`：离心管
- `GX-LC-BAG`：取样袋

打印耗材：

`GX-LB-规格`

- `GX-LB-6080`：60×80mm 合格证标签纸

## 五、打印、终端、软件和服务型号规则

- `GX-PR-6080B`：合格证标签打印设备，适配 60×80mm 标签，蓝牙连接方向
- `GX-DT-S01`：数据上传终端标准型
- `GX-SW-QJY-1Y`：谷芯快检云 1 年服务
- `GX-SV-INST`：快检室安装培训服务
- `GX-SV-CAL`：检测仪维护校准服务
