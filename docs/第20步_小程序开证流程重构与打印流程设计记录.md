# 第20步 小程序开证流程重构与打印流程设计记录

## 本次问题审计

原小程序开证入口偏向“从检测记录列表绕到开证”，不符合客户真实使用习惯；二级页面返回不够清楚；合格证字段没有充分体现承诺达标合格证的承诺事项、承诺依据、承诺主体、联系方式、开具时间等核心信息；打印入口不明确，客户容易误以为已经支持真实蓝牙打印。

## 本次重构内容

1. 小程序新增独立“开具合格证”流程：先选择承诺依据，再选择检测记录或上传依据资料，最后填写开证信息并生成合格证。
2. 承诺依据支持三类：自行检测合格、质量安全控制符合要求、委托检测合格。
3. 自行检测合格必须选择合格且状态正常的检测记录。
4. 质量安全控制符合要求、委托检测合格必须上传至少一份图片或 PDF 依据资料。
5. 合格证详情、开证记录、打印预览、打印机连接页面完成视觉和交互优化。
6. public-h5 扫码公开页同步展示承诺依据、承诺事项、公开依据资料。
7. 后台“小程序预览页”同步新流程，方便浏览器内预览。

## 数据库与接口

本次新增 Prisma migration，用于让合格证支持可选检测记录、承诺依据类型、承诺事项、打印份数、依据资料关联等字段。

新增客户侧接口：

- `POST /api/client/certificates/evidence-files`

修改客户侧接口：

- `POST /api/client/certificates`
- `GET /api/client/certificates`
- `GET /api/client/certificates/{id}`

修改公开接口：

- `GET /api/public/certificates/{publicToken}`

## 打印设计

当前仅支持模拟打印。小程序增加“打印机连接”页面，用于说明真实打印待接入；打印预览页仍只写入模拟打印日志，不调用蓝牙、不接优博讯 SDK、不申请蓝牙权限。

## 部署状态

本地 backend、admin-web、public-h5、miniapp 构建已通过。当前机器无法免密 SSH 登录 ECS，服务器部署需要手动执行或先配置临时 SSH 公钥。
