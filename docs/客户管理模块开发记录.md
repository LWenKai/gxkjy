# 客户管理模块开发记录

## 开发目标

本次新增“客户管理”模块，用于山西谷芯科技内部销售管理、客户维护、设备档案、报价记录、耗材采购与复购提醒。

该模块仅面向后台超级管理员，不开放给客户企业端、小程序端和扫码公开页，不改变检测数据、合格证、企业账号、设备绑定等既有业务流程。

## 新增数据库

新增 migration：

`backend/prisma/migrations/20260715093000_customer_management/migration.sql`

新增字段：

- `admin_users.role`：管理员角色，默认 `super_admin`，用于第一版客户管理入口控制。

新增表：

- `customers`：客户基础资料。
- `customer_needs`：客户需求记录。
- `customer_devices`：客户设备档案。
- `customer_follow_records`：客户跟进记录。
- `customer_quotes`：客户报价记录。
- `customer_purchases`：客户采购与复购记录。

删除策略：

- 客户和子记录均使用 `deleted_at` 软删除，不物理删除历史数据。

## 新增接口

所有接口均为后台接口，需管理员 JWT，并额外要求 `super_admin`。

- `GET /api/admin/customers`：客户列表，支持关键词、来源、类型、阶段、价值类型筛选。
- `POST /api/admin/customers`：新增客户。
- `GET /api/admin/customers/:id`：客户详情。
- `PUT /api/admin/customers/:id`：更新客户基础资料。
- `DELETE /api/admin/customers/:id`：软删除客户。
- `GET /api/admin/customers/repurchase-reminders`：7 天内复购提醒。
- `POST /api/admin/customers/:id/needs`：新增需求记录。
- `POST /api/admin/customers/:id/devices`：新增设备档案。
- `POST /api/admin/customers/:id/follow-records`：新增跟进记录。
- `POST /api/admin/customers/:id/quotes`：新增报价记录。
- `POST /api/admin/customers/:id/purchases`：新增采购记录。
- `DELETE /api/admin/customers/needs/:recordId`：软删除需求记录。
- `DELETE /api/admin/customers/devices/:recordId`：软删除设备档案。
- `DELETE /api/admin/customers/follow-records/:recordId`：软删除跟进记录。
- `DELETE /api/admin/customers/quotes/:recordId`：软删除报价记录。
- `DELETE /api/admin/customers/purchases/:recordId`：软删除采购记录。

## 后台页面

新增菜单：

- 销售管理
  - 客户管理

新增页面：

- `/customers`：客户列表页。
- `/customers/:id`：客户详情页。

列表页能力：

- 搜索客户企业、联系人、电话、微信、地址。
- 按客户来源、客户类型、客户阶段、价值类型筛选。
- 新增、编辑、查看详情、软删除客户。
- 展示最近跟进时间和最近采购/预计补货信息。

详情页能力：

- 基础资料。
- 需求记录。
- 设备档案。
- 跟进时间线。
- 报价记录。
- 采购记录。
- 复购提醒。

后台首页新增：

- “近期需要跟进客户”模块，展示预计 7 天内需要补货的采购记录。

## 安全与影响范围

- 未新增客户企业端接口。
- 未新增 public 接口。
- 未影响小程序登录、开证、打印预览。
- 未影响扫码页。
- 未返回密码、密钥、JWT、厂家 access_secret。
- 客户管理仅超级管理员可见可用。
