# 谷芯快检云扫码公开页说明_临时测试版

> 本说明适用于当前临时 IP 测试环境。正式域名和 HTTPS 配置完成后，公开页地址会从 IP 地址切换为正式域名。

## 1. 扫码公开页用途

扫码公开页用于展示合格证公开信息。消费者、采购方、现场人员或监管查看人员打开链接后，可以看到：

- 合格证基础信息。
- 产品信息。
- 检测结果。
- 检测项目明细。
- 企业公开资料。
- 技术支持说明。

当前公开页用于第一版演示和测试，不等同于第三方检验检测机构出具的检验报告。

## 2. 查询有效状态说明

当合格证状态正常时，页面会显示“查询有效”。

正常页面会展示：

- 合格证编号。
- 合格证类型。
- 产品名称。
- 数量和单位。
- 产地。
- 开证企业。
- 联系电话。
- 开证日期。
- 检测结论。
- 检测项目明细。

## 3. 作废状态说明

当合格证已作废时，页面会明显显示“合格证已作废”。

作废页面仍可展示基础信息和检测结果，但会明确提示该合格证已经失效，避免被误认为仍然有效。

## 4. 无效链接说明

如果链接错误、公开标识不存在或被随意修改，页面会显示“未查询到对应合格证信息”。

无效链接页面不会展示假数据，也不会要求用户登录。

## 5. 页面展示哪些信息

公开页可能展示：

- 合格证编号。
- 合格证类型。
- 产品名称。
- 数量和单位。
- 产地。
- 开证主体。
- 联系电话。
- 开证时间。
- 检测结论。
- 检测项目、检测方法、检测值、单位、限量值、判定结果。
- 企业名称、简介、主营产品、展示地址、展示电话。
- 企业公开图片和资质图片。
- 技术支持和风险说明。

## 6. 页面不展示哪些内部信息

公开页不会展示：

- 客户登录账号。
- 客户密码。
- 后台管理员信息。
- 设备编号。
- 厂家编码。
- 厂家密钥。
- 服务器密钥。
- 内部操作日志。
- 数据库字段名。
- 系统内部 token。

## 7. 企业公开资料展示规则

企业公开资料展示需要同时满足：

1. 后台已维护企业公开资料。
2. 已打开“启用公开展示”。
3. 系统设置允许显示企业公开资料模块。

如果企业资料未启用或未填写，公开页不会显示空白模块。

## 8. 图片展示规则

当前测试阶段不做真实 OSS 上传，只支持录入图片 URL。

图片展示需要满足：

1. 图片已在后台企业公开资料中录入。
2. 图片设置为公开展示。
3. 图片 URL 能正常访问。

如果图片无法加载，页面不会影响其他信息展示。

## 9. 技术支持信息展示规则

公开页底部技术支持文案来自后台“系统设置”。

当前默认说明：

- 技术支持：由山西谷芯科技有限公司 / 谷芯快检云提供技术支持。
- 风险说明：本页面展示的检测数据来源于企业快检记录，用于日常自检、留档和合格证信息展示，不等同于第三方检验检测机构出具的检验报告。

后台可以调整公开页底部说明，但不能填写服务器密码、数据库密码、密钥等敏感信息。

## 10. 当前临时 IP 测试说明

当前公开页访问格式：

`http://182.92.75.122/c/{publicToken}`

示例：

- 正常合格证：`http://182.92.75.122/c/f600b41e76e1c4504aacbc8a13de3344`
- 作废合格证：`http://182.92.75.122/c/9ea7a4e2031482df5eccdb2b92959de9`
- 无效链接：`http://182.92.75.122/c/invalid-token`

注意：

- 当前没有 HTTPS。
- 当前不适合对外正式使用。
- 当前仅用于内部测试和演示。

## 11. 正式域名 HTTPS 后的变化

域名实名认证和 HTTPS 配置完成后，公开页地址会切换为类似：

`https://cert.gxkjy.com/c/{publicToken}`

切换后需要验证：

- 旧测试链接是否需要重新生成。
- 小程序生成的扫码链接是否使用新域名。
- 微信小程序合法请求域名是否配置完成。
- 公开页在微信内置浏览器中是否能正常打开。
